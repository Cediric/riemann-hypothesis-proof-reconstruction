## 1. Prime-power norm：精确公式

源码：[NormPowPrimePowSubOne.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/NormPowPrimePowSubOne.lean)

### 1.1 一步公式

若：

\[
\|u-1\|<\|\ell\|,
\]

则：

\[
\boxed{
\|u^\ell-1\|
=
\|u-1\|\,\|\ell\|.
}
\]

证明：

\[
u^\ell-1=(u-1)(1+u+\cdots+u^{\ell-1}).
\]

所以只需证明：

\[
\|1+u+\cdots+u^{\ell-1}\|=\|\ell\|.
\]

写成：

\[
\sum_{i<\ell}u^i
=
\ell+\sum_{i<\ell}(u^i-1).
\]

对每个 i：

\[
u^i-1=(u-1)(1+u+\cdots+u^{i-1}),
\]

且 PadicInt 的单位范数不超过 1，因此：

\[
\|u^i-1\|\le\|u-1\|.
\]

非阿基米德三角不等式给出：

\[
\left\|\sum_{i<\ell}(u^i-1)\right\|
\le\|u-1\|<\|\ell\|.
\]

因此在 \(\ell\) 与误差项相加时，较大的范数项不会被抵消：

\[
\left\|\ell+\sum_{i<\ell}(u^i-1)\right\|
=\|\ell\|.
\]

### 1.2 迭代公式

若：

\[
\|u-1\|=\|\ell\|^k,\qquad k\ge2,
\]

则：

\[
\boxed{
\|u^{\ell^n}-1\|=\|\ell\|^{k+n}.
}
\]

证明对 n 归纳。

归纳假设：

\[
\|u^{\ell^n}-1\|=\|\ell\|^{k+n}.
\]

因为 \(k+n\ge2\)，所以：

\[
\|u^{\ell^n}-1\|<\|\ell\|.
\]

对 \(u^{\ell^n}\) 应用一步公式，得到：

\[
\|u^{\ell^{n+1}}-1\|
=
\|\ell\|^{k+n+1}.
\]

这就是 congruence chain 中 character 值逐层进入更深模数的依据。

## 2. Exact-level adjustment：从模 ℓ^m 进入模 ℓ^{m+1}

源码：[PadicIntExistsPowSubNormLeOfExactLevel.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4)

输入：

\[
\|u-1\|=\|\ell\|^m,
\]

\[
\|v-1\|\le\|\ell\|^m,
\qquad m\ge1.
\]

结论：

\[
\boxed{
\exists i\in\mathbb N,\quad
\|u^i-v\|\le\|\ell\|^{m+1}.
}
\]

### 2.1 将范数条件改写成整除条件

利用 PadicInt 的 norm/span 关系：

\[
\|x\|\le\|\ell\|^m
\iff
\ell^m\mid x.
\]

因此存在 a,b，使：

\[
u=1+\ell^m a,
\qquad
v=1+\ell^m b.
\]

由 u 的 exact-level 条件得到：

\[
\|a\|=1,
\]

所以 a 是 unit。

### 2.2 选择指数 i

取 a 的逆元 \(a^{-1}\)，令：

\[
i=\operatorname{appr}_1(a^{-1}b).
\]

PadicInt.appr_spec 给出：

\[
i-a^{-1}b\in\ell\mathbb Z_\ell.
\]

等价于：

\[
ia-b\in\ell\mathbb Z_\ell.
\]

### 2.3 二项式展开

对任意 x 和自然数 i，证明：

\[
(1+x)^i=1+ix+x^2d
\]

其中 d 依赖于 x 和 i。

代入：

\[
x=\ell^m a.
\]

得到：

\[
u^i
=
1+i\ell^m a+\ell^{2m}a^2d.
\]

而：

\[
v=1+\ell^m b.
\]

因此：

\[
u^i-v
=
\ell^m(ia-b)+\ell^{2m}a^2d.
\]

第一项因为 \(ia-b\) 再多一层 \(\ell\) 整除，至少落入 \(\ell^{m+1}\)。

第二项因为 \(2m\ge m+1\)，同样落入 \(\ell^{m+1}\)。

故：

\[
\|u^i-v\|\le\|\ell\|^{m+1}.
\]

## 3. Congruence chain：有限 quotient 的完整证明

源码：[CyclotomicAlgHomSubDvdOfXDvd.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4)

给定：

\[
\eta:G\to\mathbb Z_\ell^\times,
\qquad \gamma\in G,
\]

以及：

\[
\|\eta(\gamma)-1\|=\|\ell\|^k,
\qquad k\ge2.
\]

定义：

\[
\phi_n:G\to
(\mathbb Z/\ell^{k+n}\mathbb Z)^\times
\]

为 \(\eta\) 经过 PadicInt.toZModPow 的复合。

再定义：

\[
H_n=\ker\phi_n.
\]

### 3.1 H_n 的范数刻画

通过：

\[
\operatorname{ker}(\mathbb Z_\ell\to\mathbb Z/\ell^m)
=
\ell^m\mathbb Z_\ell,
\]

得到：

\[
\boxed{
g\in H_n
\iff
\|\eta(g)-1\|\le\|\ell\|^{k+n}.
}
\]

### 3.2 正规性与指数

因为 H_n 是群同态的 kernel，所以正规。

由第一同构定理：

\[
[G:H_n]\simeq\operatorname{range}(\phi_n).
\]

于是：

\[
[G:H_n]
\le
\#(\mathbb Z/\ell^{k+n}\mathbb Z)^\times
\le
\ell^{k+n}.
\]

同时 index 非零。

### 3.3 γ 的幂进入 H_n

由 prime-power norm 公式：

\[
\|\eta(\gamma^{\ell^n})-1\|
=
\|\ell\|^{k+n}.
\]

因此：

\[
\gamma^{\ell^n}\in H_n.
\]

### 3.4 每个 H_n 陪集由 γ 的幂推进

给定 \(h\in H_n\)。

有：

\[
\|\eta(\gamma^{\ell^n})-1\|
=
\|\ell\|^{k+n},
\]

而：

\[
\|\eta(h)-1\|\le\|\ell\|^{k+n}.
\]

应用 exact-level adjustment，存在 i：

\[
\|\eta(\gamma^{\ell^n})^i-\eta(h)\|
\le\|\ell\|^{k+n+1}.
\]

等价于：

\[
\eta\left((\gamma^{\ell^n})^{-i}h\right)
\equiv1\pmod{\ell^{k+n+1}}.
\]

因此：

\[
(\gamma^{\ell^n})^{-i}h\in H_{n+1}.
\]

也就是说：

\[
\boxed{
H_n=
\bigcup_{i=0}^{\ell-1}
\gamma^{i\ell^n}H_{n+1}.
}
\]

这正是 partial trace 递推所需要的有限层分解。

## 4. 与 V3.17 的组合

现在所有输入都闭合：

\[
\begin{aligned}
&\|\eta(\gamma)-1\|=\|\ell\|^k\\
&\Downarrow\\
&\| \eta(\gamma)^{\ell^n}-1\|
=\|\ell\|^{k+n}\\
&\Downarrow\\
&H_n=\ker(\eta\bmod\ell^{k+n})\\
&\Downarrow\\
&[G:H_n]\le\ell^{k+n}\\
&\Downarrow\\
&H_n=\bigcup_{i<\ell}\gamma^{i\ell^n}H_{n+1}\\
&\Downarrow\\
&\text{partial trace contraction}\\
&\Downarrow\\
&\left\|\sum_{i<\ell^n}\gamma^i x\right\|
\le\rho^n\|x\|.
\end{aligned}
\]

V3.16 的 TateCharacterFiniteOnInertia 证明因此不再缺少 prime-power norm 或 congruence chain 的算术输入。

## 5. 仍需注意的边界

- exact-level adjustment 要求 \(m\ge1\)；
- prime-power norm 迭代要求初始 level \(k\ge2\)；
- H_n 的 index bound 依赖 \(\ell\ne0\)；
- Galois character 必须确实取值于 \(\mathbb Z_\ell^\times\)；
- 部分迹递推还要求 H_n 正规以及相应的 inertia action 固定条件。

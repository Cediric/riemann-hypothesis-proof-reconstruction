## 0. 本轮要解决的疑问

V3.14 追踪 FontaineBcris 时发现，Regular 证明使用 Bcris 的 Galois invariants，PeriodData 结构中又有 invB、invdR 两个字段。

本轮重点确认：

- 这些字段是不是作为未解释的输入假设？
- Core 从哪里构造？
- PeriodData 如何构造？
- Bcris 与 BdR 的 Galois invariants 如何证明？
- 最终 LocPrime / LocTheory 是否真正由 theorem 构造？

结论：

**invB 与 invdR 并不是任意留给最终证明的字段。Core 由根单位、tilt、Acris/BdR+ 映射等数据构造；PeriodData 由 exists_realPD 构造，而 invB/invdR 分别由 Bcris 和 BdR 的 Galois invariants 定理提供；LocPrime 与 LocTheory 再由这些构造项产生。**

这补上了 V3.14 中一个重要的来源审计边界。

## 3. BdR Galois invariants：由 theta、filtration 与 Ax–Sen–Tate 控制

源码：[BdRGaloisInvariantsEqFinExt.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/IwasawaDecomposition/BdRGaloisInvariantsEqFinExt.lean)

目标：

\[
b\in B_{\mathrm{dR}},
\quad
g(b)=b\ \forall g\in G_K
\Longrightarrow
b\in K.
\]

证明依赖：

- BdR+ 是离散赋值环；
- BdR 是其分式域；
- Fontaine \(\xi\) 生成正 filtration；
- theta 映射满射且 kernel 为 \(\xi\)；
- theta section 的 Galois equivariance；
- Fontaine \(t\) 是 BdR+ 的 uniformizer；
- cyclotomic character 的作用；
- Ax–Sen–Tate fixed closure；
- Tate twist invariant vanishing。

### 3.1 两个抽象引理

**inv_ker_eq_zero：**

若 \(z\) 满足：

\[
\theta(z)=0,\qquad g(z)=z,
\]

则利用 \(\ker\theta=(t)\) 和 Tate twist invariant vanishing，逐次证明：

\[
t^n\mid z
\quad\forall n.
\]

由 BdR+ 的 separatedness：

\[
z=0.
\]

**eigen_eq：**

若：

\[
g(y)=\chi(g)^n y,
\]

则归纳证明：

\[
y=t^n w,
\qquad g(w)=w.
\]

### 3.2 对任意 BdR 不变量应用

先将：

\[
b\in B_{\mathrm{dR}}
\]

写为 \(y_0/\xi^n\)，再乘以 \(t^n\)，得到 BdR+ 中的元素 \(y\)。

由于 b Galois 不变，y 是 cyclotomic character 的 n 次特征向量。

由 eigen_eq：

\[
y=t^n w
\]

且 w Galois 不变。

然后 Ax–Sen–Tate fixed closure theorem 给出：

\[
\theta(w)\in K.
\]

使用 theta section 的唯一等变性质，得到：

\[
w=C.o(k)
\]

其中 \(k\in K\)。

最终：

\[
b=C.o(k).
\]

因此 invdR 被证明。

## 4. Bcris Galois invariants：Frobenius 轨道有限，再用周期投影

源码：[GaloisInvariantsBcrisEqMaxUnramified.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/IwasawaDecomposition/GaloisInvariantsBcrisEqMaxUnramified.lean)

目标：

\[
b\in B_{\mathrm{cris}},
\quad
g(b)=b\ \forall g\in G_K
\Longrightarrow
b\in K_0.
\]

### 4.1 periodic：证明 Frobenius 轨道有限

定义：

\[
S=\{x\in B_{\mathrm{cris}}:
g(x)=x\ \forall g\in G_K\}.
\]

因为 Frobenius 与 Galois 作用交换，S 在 Frobenius 下稳定。

对每个 \(x\in S\)，BdR invariant theorem 给出：

\[
\iota(x)\in K.
\]

再利用 FundamentalExact：

\[
\varphi(x)=x,\quad \iota(x)\in\mathrm{Fil}^0
\Longrightarrow x\in\mathbb Q_\ell^{\mathrm{nr}}.
\]

这使得一个满足固定点条件的元素可以由最大非分歧扩张中的系数表示。

对任意 \(b\in S\)，考虑：

\[
b,\varphi(b),\varphi^2(b),\ldots
\]

它们的 BdR 像都落在有限扩张 K 中，因此满足同一个有限次多项式。有限根集合迫使这个 Frobenius 轨道出现重复项：

\[
\varphi^{i+N}(b)=\varphi^i(b).
\]

利用 Frobenius 的单射性：

\[
\varphi^N(b)=b.
\]

### 4.2 选择精确周期 N 的根单位

构造：

\[
\zeta\in K_0,
\]

满足：

\[
\sigma^N(\zeta)=\zeta,
\]

且对 \(0<i<N\)：

\[
\sigma^i(\zeta)\ne\zeta.
\]

做法是取阶为：

\[
\ell^N-1
\]

的 primitive root，并利用：

\[
\sigma(\zeta)=\zeta^\ell.
\]

### 4.3 使用周期权重和投影到不变量部分

利用：

\[
\mathrm{mem\_range}
\]

构造：

\[
\sum_{i=0}^{N-1}
u\bigl((\sigma^i\zeta)^n\bigr)\,
\varphi^i(b)
\]

并证明该和属于 \(u(K_0)\)。

然后取多项式：

\[
P(X)=\prod_{0<j<N}(X-\sigma^j(\zeta)).
\]

在所有 \(i\ne0\) 的项上，P 消失；在 \(i=0\) 的项上，P 不为零。

因此：

\[
P(\zeta)b\in u(K_0).
\]

除以非零的 \(P(\zeta)\)，得到：

\[
b\in u(K_0).
\]

于是 invB 被证明。

## 5. 这两条 invariant 证明之间没有循环依赖

当前源码依赖方向：

\[
\mathrm{InvDR}
\Longrightarrow
\mathrm{InvCris}.
\]

具体而言：

- InvDR 使用 Ax–Sen–Tate fixed closure、BdR+ filtration、theta 和 cyclotomic twist；
- InvCris 使用 InvDR、Frobenius fixed/Fil⁰ kernel theorem 和最大非分歧扩张的周期投影；
- exists_realPD 再将 InvDR 与 InvCris 填入 PeriodData；
- FontaineBcris 的 Regular 再使用 InvCris。

没有发现 InvDR 反向依赖 InvCris，或 InvCris 反向依赖最终 Regular 的证据。

因此本轮这部分依赖图在源码层面呈现为有向无环结构。

## 1. `Tools_k` 究竟包含什么

`GalTPDefs.lean` 中的结构共有 14 个字段：

| 字段 | 目标命题 | 本轮识别的作用 |
|---|---|---|
| `swFull` | `SWFullX_k` | 完整的 Siegel–Weil / unfolding 输入 |
| `boxSec` | `BoxSecX_k` | Box 截面与有限层不变性 |
| `dbl` | `DblX_k` | doubling 数据 |
| `stab2` | `Stab2Cpt_k` | 特定稳定子紧性 |
| `cpt` | `CptAll_k` | 酉群紧性/基本域性质 |
| `basic` | `ThetaBasic_k` | Theta 核连续性、不变性与增长控制 |
| `polSch` | `PolSch_k` | 多项式数据属于 Schwartz 空间 |
| `unfold0` | `Unfold0_k` | Eisenstein 级数的零点/基本 unfolding 恒等式 |
| `pairEx` | `PairEx_k` | 模型与 Weil 表示配对存在 |
| `split` | `SplitModel_k` | 局部线性分解数据 |
| `vacFix` | `VacFix2_k` | vacuum 在指定局部作用下的固定性 |
| `acts` | `ActsEx_k` | 局部 Schwartz 表示作用存在 |
| `lie1` | `LieFirst` | 实 Lie 代数一阶作用 |
| `lie2` | `LieSecond` | 实 Lie 代数二阶作用 |

注意：`Tools_k` 是一个 `Prop` 结构，字段不是任意数据，而是需要逐一证明的命题。

## 2. `tools_holds_k` 的真实构造顺序

`TPGHolds.lean` 的核心结构可以按以下顺序读：

```lean
p1 := siegelWeilAniso_of_k
  siegelWeilStd_k frameConj_k finLevel_k stab2Cpt_k

l1 := boxSecX_of_k finLevel_k stab2Cpt_k

l2 : LieSecond :=
  lieSecond2 localLift_holds derEx

{ swFull := swFullX_of_k p1.2 (eisContinues_of_k eisBL_k frameConj_k) l1
  boxSec := l1
  dbl := dblX_k
  stab2 := stab2Cpt_k
  cpt := cptAll_of_k grpTop_of epsOf_of_k
    (siegelAll_of siegelSetUnitary_of_core) finVolU unimodularity_holds
  basic := thetaBasic_k
  polSch := polSch_k
  unfold0 := unfold0_k
  pairEx := pairEx_of_k modelEx_k weilEx_k
  split := splitFree_k
  vacFix := vacFix2_k
  acts := actsEx_k
  lie1 := lieFirst l2
  lie2 := l2 }
```

这段代码非常关键：它把前面看起来像“巨型黑箱”的 `Tools_k` 拆成了可单独追踪的来源。

## 3. 重点字段的数学来源

### 3.1 `cpt`：紧性来自 Siegel 集与 Haar 有限性

构造链：

`cptAll_of_k`
[
Leftarrow
	ext{GrpTop}+	ext{EpsOf}+	ext{SiegelAll}+	ext{FinVolU}+	ext{Unimod}.
]

各项来源：

- **`GrpTop`**：`FrameEstimates/GrpTop.lean` 证明 (UA) 是局部紧、第二可数、Hausdorff；有理点群可数且离散；矩阵映射连续；紧集上高度函数有界。
- **`EpsOf`**：`ThkEstEpsOf.lean` 从无限处 Hermitian/skew-Hermitian 形式的 signature 得到 (r+s=n)，并证明好框架秩不超过 (min(r,s))。
- **`SiegelAll`**：`FrameEstimates/SiegelAll.lean` 的 `siegelAll_of` 从 `Published.SiegelSetUnitary` 构造 good frame，并给出 Siegel cover、积分估计和 torus-height 控制。
- **`FinVolU`**：`FrameEstimates/FundamentalDomainFiniteVolume.lean` 将酉群商的基本域有限体积定理转成 `FinVolU`。
- **`Unimod`**：`CartanFactorisation/Unimod.lean` 证明相关酉群 Haar 测度的 unimodularity。

最重要的子链是 `SiegelSetUnitary`：

`siegelSetUnitary_of_core` 并非一个未展开的“文献假设”。它定义在 `WeilTheta.lean`，由
`siegel_of_core siegelCore_holds` 得到；而 `siegelCore_holds` 又是
`GlobalTheory.CompanionTheory.SiegelRed.siegelCore` 的别名。

`GlobalProofs/SiegelSetUnitary.lean` 中的 `siegelCore` 证明依次使用：

1. Archimedean (K_infty)-Iwasawa 分解；
2. 有限 adelic Iwasawa 紧子群；
3. 将两侧拼成全局紧子群；
4. 构造紧的 Siegel 截面 (Omega) 与正的 cone 参数；
5. 证明共轭集合紧；
6. 得到 cusp form 的 Siegel 高度界与快速衰减。

`SiegelOfCore.lean` 再把这个 core 转化为公开命题 `Published.SiegelSetUnitary)，并通过 cone 积分有限性得到所需积分估计。

因此，“`UpperTheory.Lit`”这个命名空间本身不能作为外部文献假设的证据：在当前固定快照里，`siegelSetUnitary_of_core` 是由源码中的 `SiegelCore` 定理推导出来的。

### 3.2 `swFull`：Siegel–Weil、Eisenstein 延拓与 Box 截面

`swFullX_of_k` 的三个输入分别是：

- `SWAnisoX_k`：各向异性版本的 Siegel–Weil 关系；
- `EisContinues_k`：Eisenstein 系列的解析延拓数据；
- `BoxSecX_k`：Box 截面关系。

其中：

- `siegelWeilAniso_of_k` 从 `SiegelWeilStd_k`、`FrameConj_k`、`FinLevel_k`、`Stab2Cpt_k` 推出各向异性版本；
- `eisContinues_of_k` 从 Eisenstein 有界性 `eisBL_k` 与 frame conjugacy 推出延拓；
- `boxSecX_of_k` 由 `FinLevel_k` 与 `Stab2Cpt_k` 构造。

而 `SiegelWeilStd_k` 的当前构造是：

`siegelWeilStd_k = siegelWeilStd_of_ct_k (ctSplit_of_k auxiliaryExistence_holds coefEx_k)`。

它继续依赖 Poisson 公式、有限处/无穷处数据和常数项分解。故本轮只能确认其调用链，不能把完整 Siegel–Weil 公式压缩成一句“由 Poisson 求和显然得到”。

### 3.3 `boxSec`、`finLevel`、`stab2`

- `FinLevel_k` 的目标是：给定紧子群和 Schwartz 函数，构造一个有限层集合 (Lambda)，使其在群作用下稳定，并让对应的 Heisenberg/Schwartz 作用固定数据。
- `Stab2Cpt_k` 使用格 (Y.L) 的 lattice 性质、局部 Cartan 界和紧集像，证明指定 stabilizer 紧。
- `BoxSecX_k` 调用 `box_kfin_k`，再用截面条件推出 `IsSec)。

这三个命题不是同一个结果的重复表述：一个控制有限层，一个控制群紧性，一个将两者转化为截面不变性。

### 3.4 `basic` 与 `polSch`

- `ThetaBasic_k` 由 `thetaBasic_of_k` 得到；后者使用 Weil 表示的 Schwartz 衰减界、Theta distribution admissibility、rational pair invariance，推出 Theta 核连续、具有有理点不变性并满足高度多项式增长。
- `polSch_k` 在 `ThkBaseDense.lean` 中通过子模 span induction 证明：`PolData` 中由 pure 数据生成的元素属于 Schwartz 空间。

其中 `weil_schwartz_decay_bound` 进一步调用统一 Schwartz 衰减定理 `schwartz_decay_uniform`，其输入包括高度界、有限处逆元界、Sobolev 控制和导数估计。

### 3.5 `unfold0`、`pairEx`、`split`、`vacFix`、`acts)

- **`unfold0`**：`Unfold0K.lean` 使用各向异性、可数有理点、Eisenstein `HasSum` 展开和基本域 unfolding，交换求和与积分并整理特征因子。
- **`pairEx`**：由 `modelEx_k` 和 `weilEx_k` 组合；前者构造模型，后者给出 Weil 表示。
- **`split`**：`TPGSplitFree.lean` 从 `exists_linW_k` 构造 `SplitModel_k`。
- **`vacFix`**：`VacFix2K.lean` 证明 vacuum 在指定的双重/局部作用下固定。
- **`acts`**：`ActsExK.lean` 调用 `Locrep.locRepEx_k`，构造每个局部位置的 Schwartz 表示作用。

### 3.6 `lie1)、`lie2)：实 Lie 代数作用

`lieSecond2` 使用：

- `localLift_holds`：由矩阵指数曲线构造局部一参数提升；
- `derEx`：实 Heisenberg 导数存在性。

先得到二阶 Lie 作用 `LieSecond`，再由 `lieFirst` 导出一阶 Lie 作用。这里的“二阶”是表示/微分作用层面的结构，不应误读为普通函数的二阶导数估计。

## 4. 顶层的真实 Lean 逻辑

`TPGHolds.lean` 的最后一行是：

```lean
theorem tLift_holds_k : TLift_k :=
  tLift_of_tools_k tools_holds_k (hgtEx_of_k stab2Cpt_k)
```

而 `TPGTop.lean` 的 `tLift_of_tools_k` 把以下分支拼在一起：

- branching 与高度存在；
- `realPair_k`；
- V2.8 已拆解的 `nonVan_k`；
- `liftAut_k`；
- `projEx`；
- `readLift_k)。

所以当前可以确认：**固定快照中的 Lean 项目确实形式化证明了 `TLift_k`，并且 `Tools_k` 在该快照中有显式构造。** 但 `TLift_k` 是一个特定 Theta-lift 存在性/权重结论；它与 RH 主命题之间还隔着全局算术主不等式及顶层连接，不能把 `tLift_holds_k` 直接改写成“RH 已经由本章证明”。

## 5. 当前审计等级与下一步

### 本轮已核实

- `Tools_k` 的 14 个字段及其实际构造位置；
- `siegelSetUnitary_of_core` 的内部来源，不是单凭命名就能判为外部公理；
- `cpt` 的 Siegel-set、有限体积、群拓扑和 unimodularity 依赖；
- `swFull` 的 Siegel–Weil、Eisenstein 延拓、Box 截面组合；
- `basic`、`polSch`、`unfold0`、`pairEx`、`split`、`vacFix`、`acts)、`lie1/lie2` 的直接来源；
- `tools_holds_k) 到 `tLift_holds_k) 的 Lean 组装。

### 尚待展开

1. `SiegelWeilStd_k) 的 `CTSplit_k)、`auxiliaryExistence_holds)、`coefEx_k)；
2. `EisBL_k) 与 `eisContinues_of_k) 的解析延拓细节；
3. `ModelEx_k)、`WeilEx_k)、`splitFree_k) 的具体表示论构造；
4. `tLift_holds_k) 后续如何进入主算术不等式 (M) 与最终 RH 命题；
5. 所有关键输入与已知数学定理之间的逐项对照，排除仅由自定义定义或过强前提造成的“形式上闭合”。

下一步优先级：**先向上展开 Siegel–Weil 标准公式的构造，再追 `TLift_k → (M) → RH` 的顶层链。**

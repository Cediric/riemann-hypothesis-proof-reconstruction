# V2.8 工作稿：Rallis、Schur 平均与 Theta Lift 非消失

> 日期：2026-11-23  
> 状态：源码级重构；不是 RH 全证明的最终人类可读版本。  
> 上游源码固定快照：`CocoSgt/riemann-hypothesis-lean@7cbf7a0c32fca1badf05931879a37c3f8a2b03b4`

本章继续 V2.7 的第十-D 节，针对以下 Lean 证明链做逐项源码核查：

`Tools_k → Rallis_k`，以及
`Tools_k + Rallis_k + Decomp_k + BumpAny_k + Datum_k + Tail_k + AbsNe + SchurStep_k → NonVan_k`。

先给结论：**这里的 Rallis 引理本身不是“Theta lift 非零”的证明。** 它给出一个积分消失判据；SchurStep 提供非零的平均恒等式；局部 bump 与尾项估计把全局积分放进一个可用的抽象测度引理 AbsNe 中。最后才由反证推出 Theta lift 非零。

## 1. 先读清楚三个目标的逻辑角色

### 1.1 `Rallis_k`：零 lift 导致某个系数积分为零

`GalTPDefs.lean` 中的 `Rallis_k`，在满足 `IsPair_k`、正维数、稳定子/高度数据、嵌入条件以及高度函数幂可积性的前提下，对加性 Haar 测度 `ν`、多项式数据 `Φ` 和满足 `IsFn` 的函数 `φ`，给出：

1. `coef om ν Φ · star (mc M φ)` 对模型测度可积；
2. 若对应 theta lift `lift M om Φ φ = 0)，则
   [
   int operatorname{coef}(g),overline{operatorname{mc}(g)},dmu(g)=0.
   ]

这里的 `IsFn` 包含连续性以及对有理点群作用的不变性。这个结论是一个**消失蕴含式**，不是正性结论，也没有单独断言局部因子非零。

### 1.2 `SchurStep_k`：不可约表示给出非零平均恒等式

`SchurStep_k` 的输入包括：

- 一个有限维复不可约表示 (V)；
- 一个表示 (ho) 及两条线性映射 (i,j)；
- 一个非零向量 (x_0)，使 (i(x_0)=f_0)、(j(x_0)=phi)；
- (i) 与 Weil 作用相容，(j) 与输入自守表示的右平移作用相容；
- 一个有限 adelic Schwartz 数据 (phi_f)。

输出是一个非零复数 (kappa)，使对所有 (cin gOff(arnothing))：
[
int_{gInf} operatorname{coef}(x),
  overline{operatorname{mc}(xc)},dmu_A(x)
=
kappa,operatorname{coef}(1),
  overline{operatorname{mc}(c)}.
]

这不是“积分自动为正”。它是 Schur 型平均：不可约性把一个不变 sesquilinear form 压缩成唯一的标量倍数，紧商上的平均再给出明确的体积/维数因子。

### 1.3 `AbsNe`：主项严格压过尾项，推出总积分非零

`SchurStep_k` 仍不足以推出非零，因为还要把局部结构拼成全局积分，并控制离开“好区域”的尾项。抽象命题 `AbsNe` 正是最后的测度论桥梁。

其条件可概括为：设 (A,B,C) 带测度，(Hsubseteq B)、(Ksubseteq C)，且 (H) 有正且有限的测度、(K) 测度有限。对可积函数 (f(x,b,c)) 假设：

- (b
otin H) 时 (f(x,b,c)=0)；
- (bin H) 时 (f(x,b,c)=s(c)m(x,c))；
- (int_A m(x,c),dmu_A=kappa c_0(c))，其中 (kappa
e0)；
- 在 (K) 上 (s(c)=1)、(c_0(c)=r>0)；
- 全局有 (|c_0(c)|le r)、(|s(c)|_ele w(c))；
- 尾部满足
  [
  int_{K^c}w(c),dmu_C(c)<mu_C(K).
  ]

则三重积分不为零。证明只有一个核心：若总积分为零，Fubini 将其拆成 (K) 上的主项和 (K^c) 上的尾项；主项大小为 (rmu_C(K))，而尾项严格小于它，矛盾。

## 2. `rallis_k` 的证明拆解

`TPGRallis.lean` 的主证明可以分成六步。

1. **紧性与基本域。** 从 `Tools_k.cpt` 取得 Hermitian 侧和 skew-Hermitian 侧的紧性/有限性数据；在 W 侧选取 `IsFundamentalDomain` 的基本域 (D)，并建立限制 Haar 测度有限。对模型测度作尺度归一化，记录非零常数。
2. **构造系数恒等式。** `polSch`、`basic`、`dbl`、`boxSec` 与 `swFull` 提供多项式数据、Theta 连续性、doubling/截面恒等式和 unfolding 关系。源码中的 `Law.diag` 把特定对角值联系到 `coef)；`Law.bound` 给出系数的高度增长上界。
3. **矩阵系数控制。** 利用基本域积分和函数不变性证明矩阵系数 `mc` 连续、有界，并满足反演共轭关系。其作用是让后续积分核具有足够的可积控制。
4. **构造复参数 Mellin 积分。** 对正高度函数 (A(g)) 及系数 (b(g))，建立
   [
   I(z)=int A(g)^{z-s_0}b(g),dmu(g)
   ]
   在半平面 (operatorname{Re}(z)>t_0+operatorname{Re}(s_0)-d/2) 内可积且全纯。私有引理 `cpow_integral_pk` 用给定的幂可积性、统一范数界和局部支配函数完成这一步。
5. **从右半平面延拓到中心点。** 在足够靠右的区域，unfolding 给出 `kpair` 与上述 Mellin 积分的恒等式。再用 `zero_of_half_pk`（归结为解析恒等定理）把等式延拓到目标中心点 (s_0=(d-n)/2)。
6. **用零 lift 导出目标积分为零。** `An.at_value` 把零 lift 转化为相应 Theta 配对积分为零；中心点的 `kpair` 展开后，消去两个已证明非零的归一化常数，得到 `Rallis_k` 所需的积分消失蕴含。

因此，本段最值得保留的自然语言结构是：**绝对收敛/全纯性 → 右半平面 unfolding 恒等式 → 解析延拓 → 中心点配对 → 零 lift 导致系数积分为零。** 不应把它简写成“Rallis 公式显然给出正数”。

## 3. `schurStep_k` 的证明拆解

这段证明把 `SameType` 中的有限维不可约表示结构真正用起来。

1. 由 `SameType` 取出 (V,ho,i,j,x_0)，并由 (j(x_0)=phi
e0) 知 (V) 非零。
2. 把 (V) 上的表示从标准酉群通过群同构转到 (gInf)，得到不可约表示 (pi)。
3. 用 (i) 与 Weil 作用的相容性证明 (ker j) 是 (pi)-不变子空间。不可约性说明 (ker j) 只能为 (0) 或 (V)；后一种与 (j(x_0)=phi
e0) 矛盾，所以 (j) 单射。
4. 将 (i(a)) 与有限 adelic 数据 (phi_f) 组合成 Schwartz 函数 (Psi(a))。用 Weil 表示的酉性证明
   [
   B_1(a,b)=int l_Digl(operatorname{boxFun}(Psi(a),overline{Psi(b)})igr)
   ]
   是不变 Hermitian 型；紧基本域积分和 (j) 的单射性保证它正定。
5. 由不可约表示上的不变 Hermitian 型唯一性，(B_1) 与参考 Hermitian 型只差一个标量；再由 Riesz 表示定理表示相应连续泛函。
6. 最后调用 `assemble_pk`：在紧商上对矩阵系数平均。其常数来自 Haar 体积除以 (dim_mathbb C V)，因 Haar 体积正且 (V
e0)，故 (kappa
e0)。

这解释了为什么 `SchurStep_k` 的假设中必须出现有限维不可约性、非零向量、同型 intertwining 数据和紧商平均；它们并非装饰性参数。

## 4. `nonVan_k`：把三条工具链拼成反证

`TPGNonVan.lean` 的证明结构如下。

### 4.1 选取有限多个局部位置并构造 bump 数据

先把输入自守函数搬到 (UA) 模型，使用矩阵系数有界定理得到矩阵系数的统一控制。由连续性和有限处局部群结构，找到单位元附近的开邻域 (N)，使 off-place 群中的元素落在 (N) 时保持 (phi) 不变。

随后：

- `BumpAny_k` 对每个有限处 (v) 选取非零 Schwartz bump (phi_v) 及局部子群 (H_vsubseteq N)；
- `Tail_k` 扩大有限集合 (S)，使 off-place 高度函数的尾积分严格小于整数点区域的测度；
- 在 (S) 上使用局部 bump，在 (S) 外使用标准 vacuum，拼成有限 adelic 数据 (phi_f)。

这一步的关键不是“随便选一个测试函数”，而是同时控制局部不变性、有限支集和全局尾项。

### 4.2 `Datum_k` 给出系数的支撑与分解

对 (H=igcup_{vin S}H_v) 对应的局部子群，`Datum_k` 给出：

- 单位处系数 (operatorname{coef}(1)
e0)；
- 若 (b
otin H)，则 (operatorname{coef}(xbc)=0)；
- 对 (bin H)，存在标量 (s(c))，使
  [
  operatorname{coef}(xbc)=s(c)operatorname{coef}(x),
  qquad |s(c)|=a(arepsilon(c,1))^{d/2};
  ]
- 若 (c) 属于全整子群 (K={c:operatorname{IntAll}(c)})，则 (s(c)=1)。

与此同时，`Decomp_k` 将整体酉群分解为 (gInf	imes gAt	imes gOff)，并提供各因子的拓扑与 Haar 测度结构。

### 4.3 Rallis 与 Schur 分别负责“零”和“主项”

- 假设 lift 为零，`Rallis_k` 说明全局系数—矩阵系数积分为零。
- `SchurStep_k` 对 (gInf) 因子积分，给出非零常数 (kappa) 乘以单位处系数与矩阵系数。
- 在 (K) 上，局部不变性使 (s(c)=1)，矩阵系数等于单位处的正数 (r)；在 (K^c) 上，矩阵系数的上界与 (|s(c)|) 的高度幂界给出尾部控制。
- `Tail_k` 保证尾部严格小于 (K) 的测度，正好满足 `AbsNe`。

于是 `AbsNe` 推出同一个三重积分非零，与 Rallis_k 给出的零相矛盾。故存在有限 adelic Schwartz 数据 (phi_f)，使
[
operatorname{lift}(M,omega,operatorname{pure}(f_0,phi_f),phicirc e^{-1})
e0.
]

## 5. 在 TLiftK 中的位置

`TPGTop.lean` 明确将以下结果代入 `tLift_of_k`：

`nonVan_k T (rallis_k T) (decomp_k T) (bumpAny_k T) (datum_k T) (tail_k T) absNe (schurStep_k T)`

这说明上述非消失链不是一条孤立的旁支，而是 TLiftK 构造中的实际输入。之后还要经过 `liftAut_k`、`projEx`、`readLift_k` 等步骤，才得到目标自守表示及其权重/局部类型信息。

`Tools_k` 本身是一个大型结构，包含 `swFull`、`boxSec`、`dbl`、`stab2`、`cpt`、`basic`、`polSch`、`unfold0`、`pairEx`、`split`、`vacFix`、`acts`、`lie1`、`lie2` 等字段。故不能把“`rallis_k` 由 `Tools_k` 推出”误读为“Rallis 只依赖一个初等假设”；它依赖的是此前构造的整套局部、表示论、紧性和 unfolding 工具包。

## 6. 本轮审计结论与剩余缺口

### 已经从源码恢复的部分

- `Rallis_k` 的精确结论是可积性加零 lift 蕴含积分为零；
- 其证明的解析发动机是高度幂可积性、复幂积分全纯性、unfolding 和解析延拓；
- `SchurStep_k` 的非零常数来自有限维不可约表示上的不变 Hermitian 型唯一性与紧商平均；
- `AbsNe` 是主项压过尾项的抽象测度论引理；
- `nonVan_k` 的构造把局部 bump、有限 adelic 数据、群分解、Schur 平均、尾项控制和 Rallis 消失判据串成严格反证；
- `TPGTop` 确认这条链实际进入 `TLift_k)。

### 仍不能宣称完成的部分

1. 本章没有重新证明 `Tools_k` 的全部字段，也没有把它们的上游文献输入全部展开。
2. 局部 bump 的存在、全局 unfolding 的几何前提、矩阵系数/高度函数的幂可积性仍各自依赖前置理论。
3. 本章只证明特定输入条件下 Theta lift 非零；它不单独推出主算术不等式 (M)，也不等于完成 RH 的人类可读证明。
4. 有限模型的 Python 精确证书只检查有限群轨道质量、分母和核算子恒等式，不验证无限维自动形式或局部 Rallis 因子。

**阶段判断：** V2.7 的“Rallis 内积公式如何真正发挥作用”已从流程图提升为可逐项检查的源码级论证；但其数学前提仍需继续向上游展开。下一步优先追 `Tools_k` 的实际构造，特别是 `swFull`、`boxSec`、`dbl`、`basic` 与 `cpt` 的来源，以及 `TPGHolds/TPGTop` 怎样把这些工具落实为 TLiftK 的输入。

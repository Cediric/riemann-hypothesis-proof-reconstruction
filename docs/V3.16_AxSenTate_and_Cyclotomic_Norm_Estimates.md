## 1. Ax lemma：有界轨道靠近固定点

源码：[BoundedOrbitHasNearbyFixedPoint.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/IwasawaDecomposition/BoundedOrbitHasNearbyFixedPoint.lean)

定理：

若 \(H\) 是 Galois 群子群，\(x\in\overline{\mathbb Q_\ell}\)，且：

\[
\|g(x)-x\|\le r
\qquad\forall g\in H,
\]

则存在 \(H\)-固定的 \(y\)，满足：

\[
\|x-y\|\le16r.
\]

常数 16 是源码中实际得到的统一常数。

### 1.1 先对有限轨道集合做归纳

定义 cst(k)，并证明：

\[
1\le\mathrm{cst}(k)\le16.
\]

归纳命题：

若 \(H\cdot x\) 包含在有限集合 \(S\) 中，且：

\[
|S|\le2^k,
\]

那么存在 H-fixed 的 y：

\[
\|x-y\|\le\mathrm{cst}(k)r.
\]

### 1.2 轨道大小较小时

若：

\[
|S|\le2^{k-1},
\]

直接调用归纳假设。

### 1.3 轨道较大时：用 Hasse derivative 降低次数

构造：

\[
f(X)=\prod_{z\in S}(X-z).
\]

因为 S 是 H-轨道的集合，f 在 H 的作用下不变。

取 Hasse derivative：

\[
p(X)=D^{[q]}f(X),
\qquad
q=|S|-2^{k-1}.
\]

于是：

\[
\deg p=2^{k-1}.
\]

由于 Hasse derivative 与系数作用兼容，p 仍然是 H-invariant polynomial。

### 1.4 找到靠近 x 的新根

先证明 Taylor 系数估计：

\[
\left\|
D^{[q]}f(x)
\right\|
\le r^{|S|-q}.
\]

再用根接近引理：

\[
\exists b\in\operatorname{Roots}(p),
\quad
\|b-x\|
\]

受 \(p(x)\) 和 leading coefficient 控制。

利用：

\[
1\le |S|\cdot
\left\|\binom{|S|}{q}\right\|_\ell
\]

得到：

\[
\|b-x\|\le\mathrm{loss}(k)r.
\]

而 p 是 H-invariant，故 H 作用会置换 p 的根。于是 b 的 H-轨道仍满足同一半径控制。

对 b 应用归纳假设，得到固定点 y。

### 1.5 常数收敛

证明：

\[
\mathrm{cst}(k+1)
=
\mathrm{cst}(k)\cdot\mathrm{loss}(k),
\]

\[
\mathrm{loss}(k)\ge1,
\]

以及：

\[
\mathrm{cst}(k)\le16.
\]

因此 Ax lemma 的常数统一为 16，与轨道大小无关。

## 2. Ax–Sen–Tate fixed closure

源码：[AxSenTateComplexPadicFixedClosure.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/IwasawaDecomposition/AxSenTateComplexPadicFixedClosure.lean)

目标：

若：

\[
x\in\mathbb C_\ell,\qquad
g(x)=x\quad\forall g\in H,
\]

则：

\[
x\in
\overline{
\{y\in\overline{\mathbb Q_\ell}:g(y)=y\ \forall g\in H\}
}.
\]

证明：

1. \(\overline{\mathbb Q_\ell}\) 在 \(\mathbb C_\ell\) 中稠密；
2. 取代数元素 a，使：
   \[
   \|x-a\|<\delta;
   \]
3. 因 x 被 H 固定：
   \[
   \|g(a)-a\|
   \le2\delta;
   \]
4. 用 Ax lemma 找到 H-fixed 的 y：
   \[
   \|a-y\|\le16\cdot2\delta;
   \]
5. 因此：
   \[
   \|x-y\|\le(2+32)\delta;
   \]
6. 令 \(\delta\) 任意小，得到 closure 结论。

所以 Ax–Sen–Tate fixed closure 在这里是由一个明确常数的有界轨道逼近定理推出的。

## 3. Cyclotomic norm：primitive ℓ-power root 的精确估值

源码：[NormSubOnePowTotient.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/IwasawaDecomposition/NormSubOnePowTotient.lean)

对 primitive root：

\[
\zeta^{\ell^{k+1}}=1,
\]

且 \(\zeta\) 的阶恰好是 \(\ell^{k+1}\)，证明：

\[
\boxed{
\|\zeta-1\|^{\varphi(\ell^{k+1})}
=
\|\ell\|.
}
\]

证明：

1. 使用 cyclotomic polynomial：
   \[
   \Phi_{\ell^{k+1}}(1)=\ell;
   \]
2. 分解：
   \[
   \Phi_{\ell^{k+1}}(X)
   =
   \prod_{\mu\text{ primitive}}(X-\mu);
   \]
3. 代入 X=1；
4. 对所有 primitive \(\mu\)，用 \(\mu=\zeta^a\) 及单位根范数估计，证明：
   \[
   \|\mu-1\|=\|\zeta-1\|;
   \]
5. 乘积共有 \(\varphi(\ell^{k+1})\) 项。

于是得到精确公式。

### 3.1 多项式系数估计

若：

\[
\deg P<\varphi(\ell^{N+1}),
\]

且 z 是 primitive \(\ell^{N+1}\)-th root，则：

\[
\boxed{
\|\ell\|\,\|P_j\|
\le
\|P(z)\|.
}
\]

证明先对 \(P\) 在 1 处 Taylor 展开，再利用：

\[
\|z-1\|^{\varphi(\ell^{N+1})}=\|\ell\|.
\]

不同次数项的范数不同；若两项范数相同，则指数差必须是 \(\varphi(\ell^{N+1})\) 的倍数，与次数上界矛盾。

非阿基米德三角不等式于是保证最大范数项不会被抵消。

## 4. Normalised trace bound

同文件中的：

\[
\texttt{CycTrace.normalised\_trace\_bound}
\]

要求：

\[
z\text{ 是 primitive }\ell^{n+m}\text{-th root},
\]

并且：

\[
a_i\in
\mathbb Q_\ell(z^{\ell^m}).
\]

结论：

\[
\boxed{
\|\ell\|\,
\left\|a_0\right\|
\le
\left\|
\sum_{i=0}^{\ell^m-1}a_i z^i
\right\|.
}
\]

证明：

1. 将每个 \(a_i\) 表示为 \(z^{\ell^m}\) 的多项式；
2. 通过 cyclotomic polynomial 取模，将多项式次数压到 \(\varphi(\ell^{n+1})\) 以下；
3. 组装成一个总多项式 P；
4. 证明 \(P(z)\) 正好等于给定的加权和；
5. 使用多项式系数估计控制 \(P\) 的常数项；
6. 该常数项就是 \(a_0\)。

这给出对 cyclotomic tower 的 partial trace 的非阿基米德下界。

## 5. 非零 Tate twist 的有限扩张不变量消失

源码：[EqZeroOfTateTwistInvariantFiniteExtension.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/IwasawaDecomposition/EqZeroOfTateTwistInvariantFiniteExtension.lean)

目标：

对有限扩张 K 和非零整数 i：

\[
\sigma(x)\chi_{\mathrm{cyc}}(\sigma)^i=x
\quad\forall\sigma\in G_K
\Longrightarrow x=0.
\]

### 5.1 先在无限 cyclotomic tower 中证明

定义：

\[
F_\infty=
\bigcup_{n\ge1}F(\zeta_{\ell^n}).
\]

Ax–Sen–Tate 证明任何满足 twist invariant 条件的 \(x\in\mathbb C_\ell\)，都可以任意精度地由 \(F_\infty\) 中元素逼近。

### 5.2 选取 twist 不平凡的 Galois 元

对足够高的层级 n，选取：

\[
g\in G_F
\]

使：

\[
\chi_{\mathrm{cyc}}(g)^i\ne1
\]

且 g 固定较低层的 cyclotomic field。

### 5.3 分解 cyclotomic tower 中的元素

对：

\[
y\in F(\zeta_{\ell^{n+m}}),
\]

写成：

\[
y=b+w,
\]

其中 b 来自较低层，w 是高层剩余部分。

使用：

\[
\texttt{estimate}
\]

证明：

\[
\|\ell\|\|b-y_0\|
\le\|y-y_0\|,
\]

并且：

\[
\|\ell\|\,\|c-1\|\,\|b\|
\le
\|g(y)c-y\|.
\]

这里 c 是 cyclotomic twist 特征值。

### 5.4 通过 trace bound 得到矛盾

对任意 \(\varepsilon>0\)，两次应用 Ax–Sen–Tate approximation，构造 \(y_0,y\) 使它们足够接近 x。

再将：

- 非零的 \(\|c-1\|\)；
- trace lower bound；
- x 的 twist relation；
- 非阿基米德三角不等式；

合并，得到：

\[
\|\ell\|\|x\|
\le
(\|\ell\|+3)\varepsilon.
\]

由于 \(\varepsilon\) 任意：

\[
x=0.
\]

### 5.5 推广到任意有限扩张

对有限扩张 K，取有限指数子群 \(G_K\subseteq G_F\)。

将 twist cocycle 沿有限商的全部陪集相乘，得到一个对整个 \(G_F\) 的非零 Tate twist invariant。

由无限 tower 情形，它必须为零；而每个因子都非零，矛盾。

因此得到有限扩张版本。

## 6. Tate character 在 inertia 上有限

源码：[TateCharacterFiniteOnInertiaOfEigenvector.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/TateCharacterFiniteOnInertiaOfEigenvector.lean)

目标：

若 \(b\in B_{\mathrm{cris}}\) 张成 Galois-stable line：

\[
g(b)=\eta(g)b,
\]

则：

\[
\eta(I_K)
\]

是有限群。

### 6.1 假设 inertia 像无限

若 \(\eta(I_K)\) 无限，则可以构造一串越来越深的子群：

\[
H_n=
\ker\left(
\eta\bmod \ell^{k+n}
\right).
\]

并证明：

\[
[I_K:H_n]\le\ell^{k+n}.
\]

### 6.2 选取 γ 使 character 仍然非平凡

选取：

\[
\gamma\in I_K
\]

使：

\[
\eta(\gamma)^{\ell^n}
\]

仍保持一个可控的非零距离。

同时：

\[
\gamma^{\ell^n}\in H_n.
\]

### 6.3 部分迹压缩

对每个 \(h\in H_n\)，可以选择：

\[
a\in\{0,\ldots,\ell-1\}
\]

使：

\[
\gamma^a h\in H_{n+1}.
\]

于是使用 partial trace：

\[
1+\gamma+\cdots+\gamma^{\ell-1}.
\]

由：

- NormInertiaPowPrimePowSubLe；
- NormGeomSumGaloisLe；
- NormInertiaPartialTraceGeometricLe；

得到几何衰减：

\[
\|\operatorname{PartialTrace}_n\|
\le \rho^n,
\qquad 0<\rho<1.
\]

### 6.4 Ax lemma 逼近固定向量

由于 b 的 Galois orbit 在 H_n 上越来越接近固定，使用 Ax lemma 得到：

\[
b_n\in B_{\mathrm{cris}}^{H_n}
\]

且：

\[
\|b-b_n\|\le16r_n.
\]

再通过 TateEstimateGaloisEigenvector，将 \(\eta(\gamma)^{\ell^n}-1\) 与逼近误差及 partial trace 联系起来。

### 6.5 指数衰减矛盾

一边由 character 的非平凡性得到一个不可能过快消失的下界；

另一边由 partial trace 的几何衰减得到 \(\rho^n\) 上界。

当 n 足够大时两者矛盾。

故 inertia 上的 character 像只能有限。

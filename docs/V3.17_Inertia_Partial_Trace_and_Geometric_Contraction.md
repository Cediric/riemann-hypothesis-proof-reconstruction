## 1. NormPowIndexLeOfFixed：有限指数固定子群控制范数

源码：[NormPowIndexLeOfFixed.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/NormPowIndexLeOfFixed.lean)

命题：

若 \(H\subset G_{\mathbb Q_\ell}\) 是有限指数子群，且：

\[
g(x)=x\quad\forall g\in H,
\qquad \|x\|<1,
\]

则：

\[
\boxed{
\|x\|^{[G:H]}\le\|\ell\|.
}
\]

证明：

1. 取有限商 \(G/H\)；
2. 构造乘积：
   \[
   c=\prod_{q\in G/H}q(x);
   \]
3. 因为 Galois 群只置换陪集，所以 c 是 Galois 不变量；
4. 使用：
   \[
   B_{\mathrm{cris}}^{G_{\mathbb Q_\ell}}
   =
   \mathbb Q_\ell^{\mathrm{nr}}
   \]
   的相应固定域结构，将 c 放入基域；
5. 每个 Galois 共轭保持范数，因此：
   \[
   \|c\|=\|x\|^{[G:H]};
   \]
6. 因 \(\|x\|<1\)，c 落入 \(\ell\)-进整数环的极大理想，故 \(\|c\|\le\|\ell\|\)。

这是一个很干净的“有限指数—范数幂次”估计。

## 2. NormSubLt：inertia 元素在模 ℓ 意义下接近 Teichmüller 根

源码：[NormSubLt.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/NormSubLt.lean)

目标：

若 \(\gamma\) 固定最大非分歧扩张，且 \(x\ne0\)，则：

\[
\boxed{
\|\gamma x-x\|<\|x\|.
}
\]

证明分成三步。

### 2.1 闭单位球的剩余域特征为 ℓ

令：

\[
\mathcal O=
\{a\in\overline{\mathbb Q_\ell}:\|a\|\le1\},
\]

\[
\mathfrak m=
\{a:\|a\|<1\}.
\]

证明：

\[
\operatorname{char}(\mathcal O/\mathfrak m)=\ell.
\]

### 2.2 每个闭单位球元素都接近 Teichmüller 型根

先在有限剩余域中证明某个幂次满足：

\[
\|a^{\ell^f}-a\|<1.
\]

再从多项式：

\[
X^{\ell^f}-X
\]

的根中选取 \(\zeta\)，得到：

\[
\|a-\zeta\|<1,
\]

其中 \(\zeta=0\)，或 \(\zeta\) 是阶与 \(\ell\) 互素的单位根。

### 2.3 inertia 固定这些根

因为 \(\gamma\) 固定最大非分歧扩张，所以：

\[
\gamma(\zeta)=\zeta.
\]

于是：

\[
\|\gamma(a)-a\|
\le
\max\bigl(
\|\gamma(a-\zeta)\|,
\|a-\zeta\|
\bigr)
<
1.
\]

再将：

\[
u=\frac{\gamma(x)}x
\]

归一化为单位，利用 \(\gamma^{\ell^n}x=x\) 和剩余域特征 \(\ell\)，得到：

\[
\|u-1\|<1.
\]

最终：

\[
\|\gamma(x)-x\|=\|x\|\|u-1\|<\|x\|.
\]

## 3. NormInertiaPowPrimePowSubLe：ℓ 次幂作用逐层收缩

源码：[NormInertiaPowPrimePowSubLe.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/NormInertiaPowPrimePowSubLe.lean)

输入：

- \(\gamma\) 固定最大非分歧扩张；
- \(H\) 是正规有限指数子群；
- \([G:H]\le\ell^m\)；
- \(\gamma^{\ell^n}\in H\)；
- \(x\) 被 H 固定。

结论：

\[
\boxed{
\|\gamma^{\ell^j}x-x\|
\le
\|\ell\|^{1/\ell^{m-j}}\|x\|,
\qquad j\le m.
}
\]

### 3.1 起始步 j=0

令：

\[
z=\frac{\gamma x-x}{x}.
\]

由 NormSubLt：

\[
\|z\|<1.
\]

同时 z 被 H 固定。

使用 NormPowIndexLeOfFixed：

\[
\|z\|^{[G:H]}\le\|\ell\|.
\]

再利用：

\[
[G:H]\le\ell^m
\]

得到：

\[
\|z\|\le\|\ell\|^{1/\ell^m}.
\]

乘回 \(\|x\|\)，得到起始估计。

### 3.2 归纳步

假设：

\[
\|\gamma^{\ell^j}y-y\|
\le s\|y\|
\]

对所有 H-fixed 的 y 成立。

令：

\[
\sigma=\gamma^{\ell^j},
\qquad
y=\sum_{a=0}^{\ell-1}\sigma^a x.
\]

使用 NormGeomSumGaloisLe：

\[
\|\sigma^\ell x-x\|
\le
\max(s^{\ell-1},\|\ell\|)\,s\,\|x\|.
\]

选择：

\[
s=\|\ell\|^{1/\ell^{m-j}},
\]

即可得到下一层指数。

## 4. NormGeomSumGaloisLe：几何和为何产生 ℓ-adic 收缩

源码：[NormGeomSumGaloisLe.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/NormGeomSumGaloisLe.lean)

设：

\[
\|\sigma(x)-x\|\le s\|x\|,
\qquad 0\le s\le1.
\]

则：

\[
\boxed{
\left\|\sum_{i=0}^{\ell-1}\sigma^i(x)\right\|
\le
\max(s^{\ell-1},\|\ell\|)\|x\|.
}
\]

证明关键恒等式：

\[
\sum_{i=0}^{\ell-1}T^i
=
\sum_{j=0}^{\ell-1}
\binom{\ell}{j+1}(T-1)^j.
\]

其中：

- \(1\le j+1<\ell\) 时，\(\ell\mid\binom{\ell}{j+1}\)；
- 最后一项 \(j=\ell-1\) 的系数为 1；
- 每个 \((T-1)^j x\) 的范数至多 \(s^j\|x\|\)。

因此中间项由 \(\|\ell\|\) 控制，最后一项由 \(s^{\ell-1}\) 控制。

同时：

\[
\sigma^\ell(x)-x
=
\sigma\left(\sum_{i<\ell}\sigma^i x\right)
-
\sum_{i<\ell}\sigma^i x,
\]

再用原始 displacement bound 得到第二个收缩因子。

## 5. CyclotomicAlgHomSubDvdOfXDvd：构造有限指数 congruence chain

源码：[CyclotomicAlgHomSubDvdOfXDvd.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/CyclotomicAlgHomSubDvdOfXDvd.lean)

给定连续字符：

\[
\eta:G_{\mathbb Q_\ell}\to\mathbb Z_\ell^\times
\]

和 \(\gamma\)，满足：

\[
\|\eta(\gamma)-1\|=\|\ell\|^k,
\qquad k\ge2.
\]

定义：

\[
H_n=
\left\{
g:
\|\eta(g)-1\|\le\|\ell\|^{k+n}
\right\}.
\]

源码将其识别为模 \(\ell^{k+n}\) 的单位群映射的 kernel。

得到：

1. \(H_n\) 正规；
2. \([G:H_n]\ne0\)；
3. \([G:H_n]\le\ell^{k+n}\)；
4. \(\gamma^{\ell^n}\in H_n\)；
5. 每个 \(h\in H_n\)，都能乘上 \(\gamma^{\ell^n}\) 的某个幂，进入 \(H_{n+1}\)。

最后一项来自：

\[
\texttt{padicInt\_exists\_pow\_sub\_norm\_le\_of\_exact\_level}.
\]

### 5.1 exact-level 调整引理

给定：

\[
\|\eta(\gamma)-1\|=\|\ell\|^m,
\qquad
\|\eta(h)-1\|\le\|\ell\|^m,
\]

存在整数 i，使：

\[
\|\eta(\gamma)^i-\eta(h)\|
\le\|\ell\|^{m+1}.
\]

证明：

- 把 \(\eta(\gamma)-1\) 和 \(\eta(h)-1\) 写成 \(\ell^m\) 的倍数；
- 证明前一个商是 unit；
- 使用 PadicInt.appr 选取 i；
- 展开：
  \[
  (1+x)^i=1+ix+x^2d;
  \]
- 通过选择 i 消去一阶项，剩余项进入下一层 \(\ell^{m+1}\)。

这给出了 congruence chain 的逐层推进。

## 6. NormInertiaPartialTraceGeometricLe：最终得到统一几何衰减

源码：[NormInertiaPartialTraceGeometricLe.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/NormInertiaPartialTraceGeometricLe.lean)

输入就是上一节构造的 H_n chain。

选择：

\[
\rho=
\|\ell\|^{1/\ell^{k+1}}.
\]

因为：

\[
0<\|\ell\|<1,
\]

所以：

\[
0<\rho<1.
\]

证明：

\[
\boxed{
\left\|
\sum_{i=0}^{\ell^n-1}\gamma^i x
\right\|
\le
\rho^n\|x\|
}
\]

只要 x 被 \(H_n\) 固定。

### 6.1 归纳构造

假设 x 被 \(H_{n+1}\) 固定，令：

\[
\sigma=\gamma^{\ell^n},
\]

\[
y=\sum_{j=0}^{\ell-1}\sigma^j x.
\]

由 H_n 的生成关系：

\[
y\in \mathrm{Fix}(H_n).
\]

由 NormInertiaPowPrimePowSubLe：

\[
\|\sigma z-z\|\le\rho\|z\|
\]

对所有 \(H_{n+1}\)-fixed 的 z 成立。

再用 NormGeomSumGaloisLe：

\[
\|y\|\le\rho\|x\|.
\]

最后将长部分迹拆分：

\[
\sum_{i<\ell^{n+1}}\gamma^i x
=
\sum_{i<\ell^n}\gamma^i y.
\]

应用归纳假设，得到：

\[
\rho^n\|y\|
\le\rho^{n+1}\|x\|.
\]

这就是 partial trace 的几何收缩。

## 1. `ordinaryEisensteinEigenfunctional_exists)：不是一个空的存在性标签

定义：[CuspidalUnitaryTwistsClaim.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Statements/CuspidalUnitaryTwists/CuspidalUnitaryTwistsClaim.lean)

它的输入包括：

- 奇素数 (l)；
- (l
e2)；
- (ege1)；
- 权重 (2e+1) 的 newform (g)；
- (l
mid g.M)；
- (|iota^{-1}(a_l(g))|=1)；
- 一个模 (l) 的 Dirichlet character (psi)；
- 正整数 (N_0)，且 (l
mid N_0)。

输出远不止一个 Hecke 特征值，而是：

1. 新模数 (N)，满足 (g.Mmid N)、(N_0mid N)、(l
mid N)、(Nge5)；
2. 两个模 (N) 的 Dirichlet character (chi,	heta)；
3. 一个单位范数复数 (alpha)，满足
   [
   alpha^2-a_l(g)alpha+chi(l)l^{2e}=0;
   ]
4. 一个 `EigAll` 结构：给出目标 Hecke 特征泛函，并对其他 nebentypus 分量给出消失；
5. 奇偶性关系
   [
   chi(-1)=-1,qquad
   	heta(-1)=(-1)^epsi(-1);
   ]
6. 一个 `MeasMu`：包含层级兼容、统一范数界、有限扩张值域和插值估计；
7. 非零常数 (v)；
8. 两个互素于 (6Nl) 的平滑参数 (c_1,d_1)，并满足若干排除退化的代数条件。

### 1.1 实际证明来源

- [OrdinaryEisensteinEigenfunctionalExists.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/FoundationProofs/OrdinaryEisensteinEigenfunctionalExists.lean)
- [OrdinaryEisensteinEigenfunctionalExistsStatement.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/FoundationProofs/OrdinaryEisensteinEigenfunctionalExistsStatement.lean)

外层的 `ordinaryEisensteinEigenfunctional_exists` 只是把已证明的 `chapterM_holds` 作为 `CuspidalUnitaryTwistsClaim` 提供给后续模块。

`chapterM_holds` 的核心构造：

1. 选取一个辅助素数 (rge l+7)，并证明 (l
mid r)；
2. 用 `depleted_newform_prim` 取得所需的 primitive character；
3. 将原 newform 的级数提升到一个更大的 (N)，使 (g.Mmid N)、(N_0mid N) 且 (l
mid N)；
4. 构造适当的 (chi,	heta,alpha)；
5. 调用 `chapterM_of_level` 得到 `EigAll)、`MeasMu)、非零插值值及平滑参数；
6. 将所有模数互素、奇偶性和非退化条件整理成 `CuspidalUnitaryTwistsClaim)。

这是一条真正的 level-raising/depletion 构造链，不是把所需特征泛函作为未解释假设直接塞入 `glue2)。

## 2. `TowerEx)：模函数塔的存在性

定义位置：[ThickFrames.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/ThickFrames.lean)

`TowerEx) 要求：对每个代数闭域 (Omega)、每个嵌入 (arepsilon:Omega	omathbb C)，存在一个 `Tower Ω ε)。

实际证明：

- [TowerEx.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/TowerEx.lean)
- [ExistsModularFunctionTowerAlgebraicCoefficients.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/FoundationProofs/ExistsModularFunctionTowerAlgebraicCoefficients.lean)

`towerEx` 调用 `exists_modular_function_tower_algebraic_coefficients)，后者调用 `GlobalTheory.FN.tower_exists)。

`tower_exists` 的构造并非只取一个抽象塔：

1. 先取得模函数分式域；
2. 取得其中的 (j)-不变量；
3. 构造上半平面的解析 germ；
4. 证明 (j)-不变量的代数生成关系；
5. 构造模群右作用与 Shimura reciprocity；
6. 证明 (q)-展开收敛、分母有界和饱和性；
7. 将这些数据组合成满足 `IsStd` 的标准模函数塔。

因此 `TowerEx) 提供的是后续 Kummer/Euler-system 构造所需要的完整模函数塔结构。

## 3. `Meas3)：把 Eisenstein 测度插值转成 (l)-进幂级数

定义：[RhoFrob.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/RhoFrob.lean)

输入包括：

- `MeasMu)；
- (l
e2)、(ege1)；
- (psi) 与符号参数 (s=(-1)^epsi(-1))；
- 非零插值值 (v)；
- 有限组 (eta_i,t_i)，其中 (l
mid t_i)；
- 非零组合条件
  [
  sum_i iota(eta_i)psi^{-1}(t_i)t_i^e
e0.
  ]

输出包括一个系数环 (c_O)、幂级数 (L)、非零常数 (kappa)、Dirichlet character (phi)，以及：

1. (L) 的所有系数都在 (c_O) 中；
2. (phi) 是 (psi^{-1}) 的 (l)-进实现；
3. 对正确奇偶性的 primitive character (psi')，在 (l^m) 阶 primitive root (z) 处，
   [
   sum_{bin(mathbb Z/l^mmathbb Z)^	imes}
      psi'(b)L(z^b)
   ]
   与 (kappa)、有限组合 (sum_ieta_ipsi'^{-1}(t_i))、Gauss sum 及 `mesMu` 的乘积在规定的 (l)-进精度下同余；
4. 相反奇偶性的 primitive character 对应的和为零；
5. 相关的加权 mass 和在充分大的层级上不可能趋于零到指定精度。

### 3.1 证明拆解

源码：[DistributionApply.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/DistributionApply.lean)

`meas3` 的主要步骤：

1. 从 `MeasMu` 和符号条件得到 `distribution_integral`，产生非零 (kappa) 与分布范数控制；
2. 调用 `exists_integral_powerSeries_of_bounded_distribution)，把有界分布转成系数整的幂级数 (L)；
3. 用 `gaussSum_twist_congr_of_measure` 把测度积分关系转成 primitive-root 处的 Gauss-sum 关系；
4. 构造 (phi=psi^{-1}circiota)；
5. 用 `riem0` 处理奇偶性；
6. 由有限组合非零和 (v
e0)，得到一个非零乘积；
7. 调用 `final`，得到 mass 和的最终非消失下界。

这里的核心不是“测度连续所以存在幂级数”，而是**有界分布的幂级数表示 + primitive-root Gauss-sum 插值 + 非零有限组合**。

## 4. `JEx)：把 valuation ring 识别成 (l)-进单位球

定义：[RhoFrob.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/RhoFrob.lean)

`JEx) 要求对 `OverL l A) 的 valuation ring (A)，存在嵌入
[
j:Omegahookrightarrowoverline{mathbb Q}_l
]
使
[
xin Aiff |j(x)|le1,
]
并且 (l) 在 (A) 中是非单位。

证明：[JEx.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/JEx.lean)

- 从 `OverL) 取得 (A) 的 valuation 数据；
- 证明 (A.valuation(l)<1)，所以 (lin A.nonunits)；
- 调用 `Examples₂.LB.exists_emb` 构造所需的 valuation-preserving embedding。

这是一个局部域/valuation 理论接口，用于把抽象 valuation ring 中的整性转成 (l)-进绝对值不等式。

## 5. `CoefUb)：有限多个有界元素可被共同系数环吸收

定义：[RhoFrob.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/RhoFrob.lean)

给定两个系数环 (c,c') 和有限集合 (Fsubsetoverline{mathbb Q}_l)，若
[
orall xin F,quad |x|le1,
]
则存在更大的系数环 (c'')，使：

- (c.Osubseteq c''.O)；
- (c'.Osubseteq c''.O)；
- (Fsubseteq c''.O)。

证明：[CoefUb.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/CoefUb.lean)

它调用：

- `UpperTheory.V.HV.coefSup`：先把两个系数环放进一个共同上界；
- `UpperTheory.V.Th.Nm.inOf`：再把有限多个单位球内元素吸收到一个更大的系数环。

这是一个有限整性整理工具，避免每次构造新的有限多个系数时都手动重建系数环。

## 6. `Mono)：扩大系数环不会破坏系统性质

定义：[RhoFrob.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/RhoFrob.lean)

若 (c.Osubseteq c'.O)，则：

1. `Sys W c y S'` 可提升为 `Sys W c' y S'`；
2. `IwSys2 c A ν Z` 可提升为 `IwSys2 c' A ν Z`；
3. `HTLawCsOfCoef A c Z j ...` 可提升为对应的 (c') 版本。

证明：[Imports.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/Imports.lean)

该证明逐个将原有坐标/系数整性通过环包含映射到新系数环。它不产生新的 Hecke 或 Galois 信息，只保证扩大系数环这一操作不破坏已经建立的结构。

## 7. 这六个输入在 `glue2` 中分别做什么

| 输入 | 数学职责 | 主要下游用途 |
|---|---|---|
| `ordinaryEisensteinEigenfunctional_exists` | 构造目标 Hecke 特征泛函、Eisenstein 插值数据和非零测度值 | Kato global-unit-law 的特征分量 |
| `TowerEx` | 构造标准模函数塔 | Kummer/Euler-system 分层数据 |
| `Meas3` | 把测度插值变成整系数幂级数与 primitive-root 关系 | `PinOf` 与局部非消失 |
| `JEx` | 构造 (l)-进 valuation embedding | 把 valuation-ring 整性转成范数界 |
| `CoefUb` | 统一有限多个系数环 | 整理新投影和 smoothed 数据的系数 |
| `Mono` | 系数环扩大时保持 `Sys/IwSys2/HTLaw` | 在 K4/K5 glue 阶段统一系数环 |

这些输入并非一个重复的大定理：它们分别解决不同的构造障碍。

## 8. 本轮结论与下一步

### 已核实

- `ordinaryEisensteinEigenfunctional_exists` 由 `chapterM_holds` 构造，包含 level raising、primitive character、Hecke 特征泛函和 `MeasMu)；
- `TowerEx) 由标准模函数塔与 (j)-不变量构造；
- `Meas3) 由有界分布、幂级数表示和 Gauss-sum 插值构造；
- `JEx) 来自 valuation-preserving embedding；
- `CoefUb) 来自系数环上界与有限集合整化；
- `Mono) 是系统性质在系数环包含下的直接保持定理。

### 下一轮优先级

继续审计剩余输入：

1. `PsiEx)：Galois 特征如何从 `KillsMu) 下降为模 (l) 的 Dirichlet character；
2. `FrobU)、`DetIne)：Frobenius 单位范数与惯性行列式关系；
3. `HatW)：Eisenstein Fourier 系数的非零性、范数界和周期性；
4. `PinOf)、`SmNz)：如何从测度与有限线性组合构造 `Pin7)；
5. `GmEx)、`ExplSmul)：模 (l) 的矩阵选择与幂次缩放；
6. `AvgEq)、`AvgMF)、`RhsEq)、`SmSys)、`ChiFix)：最终的平均恒等式、Hecke 模形式识别和 smoothing 拼接。

仍需对 `ordinaryEisensteinEigenfunctional_exists) 的上游 `chapterM_of_level)、`depleted_newform_prim) 以及模形式特征泛函构造做更细的独立数学解释；当前只是追到它们的证明调用链。

## 1. 本轮结论

FontaineBcris 在源码中被定义为七个字段的合取：

\[
\begin{aligned}
\mathrm{FontaineBcris}:\quad
&T.\mathrm{TensorInj}\\
{}\land{}&T.\mathrm{PhiInj}\\
{}\land{}&T.\mathrm{IotaInj}\\
{}\land{}&T.\mathrm{Fund}\\
{}\land{}&\mathrm{PhiSubOneOntoFilZero}\\
{}\land{}&T.\mathrm{FundOnto}\\
{}\land{}&T.\mathrm{Regular}.
\end{aligned}
\]

关键源码：[OneSubPhiOntoOfFilZero.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/PublishedTheorems/GaloisCohomology₂/OneSubPhiOntoOfFilZero.lean)。

七项并不是七条互不相关的证明链。源码中的 FontaineBcris.of_rest 将最终构造缩减为四个输入：

\[
\boxed{
\mathrm{TensorInj}\land\mathrm{Fund}\land
\mathrm{FundOnto}\land\mathrm{Regular}.
}
\]

其余三项由已有结果组装：

- PhiInj：phiB_injective；
- IotaInj：ULaws.u_laws 给出的周期映射单射性；
- PhiSubOneOntoFilZero：由 one_sub_phi_onto 与 filZero_of_onto 组合。

更进一步，regular_of_tensorInj 的 TensorInj 参数在函数体中被直接丢弃。Regular 的实际证明来自 core_regular，不是 TensorInj 的推论。这里不存在由 TensorInj 反过来证明自身的循环。

## 2. 七个字段的精确定义与证明状态

| 字段 | 数学内容 | 源码证明入口 |
|---|---|---|
| TensorInj | 最大非分歧扩张上线性无关的有限族，在 Bcris/BdR 张量关系中系数只能全为零 | TensorInj.tensorInj |
| PhiInj | Bcris 上的 Frobenius 映射单射 | phiB_injective |
| IotaInj | 周期映射 ι：Bcris → BdR 单射 | ULaws.u_laws |
| Fund | Frobenius 固定且落在 Fil⁰ 的 Bcris 元素来自 Q_l | fundamental_exact |
| PhiSubOneOntoFilZero | 对任意 y，存在 x，使 ι(x)∈Fil⁰ 且 φ(x)−x=y | filZero_of_onto |
| FundOnto | 对任意 BdR 元素 w，存在 Frobenius 固定的 b，使 ι(b)−w∈Fil⁰ | FundOnto.fundOnto |
| Regular | 在有限扩张 K 上，任何非零的 G_K 稳定标量直线生成元都是 Bcris 单位 | core_regular |

完整定义位于 [AcrisTorsionFreeComplete.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Definitions/NonGaloisDescent/AcrisTorsionFreeComplete.lean)。

注意：PhiSubOneOntoFilZero 与 OneSubPhiOnto 的符号方向不同。后者要求解：

\[
x-\varphi(x)=y,
\]

前者要求：

\[
\varphi(x)-x=y,\qquad \iota(x)\in\mathrm{Fil}^0.
\]

不能把二者当作同一个命题。

## 3. Core：周期环数据并非凭空假设

### 3.1 Core 的二十个字段

Core l 是一个具体的周期环数据包，共二十个字段，可按功能分组：

1. 相容单位根系统：ζ、ζ_zero、ζ_succ、ζ_one；
2. tilt 元素及其根关系：ε、ε_root；
3. BdR⁺ 截面：o、o_sec；
4. Acris 到 BdR⁺ 的映射及性质：j、j_cris；
5. Bcris 到 BdR 的映射及兼容性：ι、ι_j；
6. 最大非分歧扩张到 Bcris 的嵌入及兼容性：u、ι_u；
7. Fontaine 周期及对数性质：t、t_log；
8. 最大非分歧扩张上的 Frobenius：σ、σ_root；
9. cyclotomic character：χ、χ_cyc。

定义和字段类型见 [IsCrisP.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Definitions/AutomorphicMembership/IsCrisP.lean)。

nonempty_core 在 [NonemptyLocalPeriodRingsData.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/IwasawaDecomposition/NonemptyLocalPeriodRingsData.lean) 中构造 Core。

### 3.3 从 LocTied 数据得到兼容 Core

[ExistsFinExt.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/ExistsFinExt.lean) 中的 FitsEx.exists_fits 给出：

\[
\mathrm{LocTied}(P,AI)\Longrightarrow
\exists C:\mathrm{Core},\ \mathrm{Fits}(T,C).
\]

Fits 逐项匹配单位根、tilt 元素、BdR⁺ 截面、ι、最大非分歧嵌入、t、cyclotomic character 与 Frobenius 数据。

### 4.1 TensorInj：从分式表示回到最大非分歧扩张上的线性无关

源码：

- [AlgClosureTensorBcrisToBdRInjective.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/AlgClosureTensorBcrisToBdRInjective.lean)
- [GaloisLinearDisjointStatement.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/GaloisLinearDisjointStatement.lean)
- [LeKurOfNorm.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/LeKurOfNorm.lean)

目标关系为：

\[
\sum_i o(x_i)\,\iota(b_i)=0
\quad\Longrightarrow\quad
\forall i,\ b_i=0,
\]

其中 x_i 在最大非分歧扩张上满足线性无关条件。

证明分为四层：

1. **分式清分母。** Bcris 是 Acris 对 t 的局部化。每个 Bcris 元素可用 Acris 分子与 t 的幂表示，从而把系数放入同一个分式域。
2. **生成子域。** 在 BdR 这个域中，取 Acris 映像生成的子域 F。利用分式表示，把 ι(Bcris) 也放入 F；再利用最大非分歧扩张到 Bcris 的嵌入，把最大非分歧扩张的像放入 F。
3. **范数识别。** [ExistsPowNorm.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/ExistsPowNorm.lean) 中的 GaussCore.norm_eq_zpow 是一条实质证明链：
   - exists_pow_norm 先利用 x 对 ℚ_l 的代数性、最小多项式常数项非零和谱范数公式，得到某个正整数 t 与整数 s，使 ‖x‖^t=ℓ^s；
   - 通过 exists_gauss_norm_extension 构造一族非阿基米德、乘法的 Gauss 范数 N_r，并用 acris_gauss_norm_eventually_monomial 得到非零 Acris 元素在 r 的某个区间上具有 c r^k 的形式；
   - homog_eq 将 C.j(a)=C.o(y)C.j(b) 转换为 a、b 满足一个首一多项式关系；通用 le_of_homog 用超度量三角不等式证明 N_r(a)≤N_r(b)。对 y⁻¹ 再做一次，得到反向不等式；
   - 两边 Gauss 范数相等，利用 exp_eq 比较区间内的幂指数，推出 ‖x‖ 必须恰好是 ℓ 的整数次幂。

   随后 [LeKurOfNorm.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/LeKurOfNorm.lean) 的 UnramValue.le_Kur_of_norm 将这个范数条件转化为最大非分歧扩张包含关系。其 integral_mem 证明先在有限扩张的整数闭包中用 Hensel 引理提升有限剩余域的 Frobenius 固定根，再用范数幂条件控制除以 ℓ 后仍然整；最后通过局部环完备性、有限剩余域和 Jacobson 根基论证，得到整个整数闭包都落在最大非分歧扩张。
4. **线性无关传递。** [GaloisLinearDisjoint.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4) 的 galois_linearDisjoint 使用原始线性无关族生成有限维中间域，取 primitive element，比较它在底域与系数子域上的最小多项式次数，从而得到其幂的线性无关性。将各个 x_i 展开到 primitive element 的幂基，再逐项比较系数，最后用线性映射延拓把关系中的每个 b_i 单独提取为零。

这不是仅凭“系数域线性无关”直接推出张量单射；中间真正承担工作的是分式域控制、Gauss 范数、最大非分歧扩张判别和 Galois 线性无交。

定理入口：[AlgClosureTensorBcrisToBdRInjectiveStatement.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/AlgClosureTensorBcrisToBdRInjectiveStatement.lean)。

#### PhiInj：Acris Frobenius 单射，再提升到 Bcris

源码：[FrobeniusPeriodRingInjective.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/IwasawaDecomposition/FrobeniusPeriodRingInjective.lean)。

证明分为两层：

1. **Acris 层。** 先选取满足 IsEps 的 tilt 元素 ε，并在 AinfP 中取 ℓ 的逆元 q。若 φ_A(x)=0，则用 Acris 的稠密性把 x 写成 Acris0 元素加任意高次 ℓ 幂误差。approx_mem 结合 xi 的饱和商完备性、Ainf 的 Frobenius 双射性和一个关于二元理想幂的整除引理，证明近似项本身可被任意高次 ℓ 幂整除。再用 bounded_mod 将其转换为 xi-adic 误差，最后通过 ev_n 与 canonicalAcrisToBdRPlusUniqueEquivariantApprox 得到 j(x)=0。由于 crisP_injective，x=0。
2. **Bcris 层。** 若 φ_B(b)=0，利用 Bcris 对周期元的局部化表示，取某个 n 与 x∈Acris，使周期元的 n 次幂乘 b 等于 x 的像。对等式施加 φ_B，使用 φB_alg 和 Acris→Bcris 的单射性，得到 φ_A(x)=0。第一层推出 x=0；再利用周期元在 Bcris 中为单位，得到 b=0。

其中 Acris→BdR⁺ 的单射性由 crisP_injective 证明：若 j(x)=0，则 x 可被 ℓ 整除；对商元重复应用 kernel-divisibility 引理，得到 x 对每个 n 都属于 ℓⁿAcris；Acris 的 ℓ-adic Hausdorff 性最终给出 x=0。其依赖的两个关键包装定理分别是 acris_divisible_of_kernel_powers 与 acris_filtration_approx_by_envelope_kernel_power。

#### IotaInj：将局部化映射延拓到 BdR 的域中

源码：

- [LocalPeriodRingsDataUnramifiedLaws.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/IwasawaDecomposition/LocalPeriodRingsDataUnramifiedLaws.lean)
- [ExistsInjectiveBcrisToBdR.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/IwasawaDecomposition/ExistsInjectiveBcrisToBdR.lean)
- [AcrisToBdRPlusInjective.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/IwasawaDecomposition/AcrisToBdRPlusInjective.lean)

具体步骤：

1. 先由 IsCrisP 条件证明 j：Acris→BdR⁺ 单射。其核心是 kernel 中的元素可被任意高次 ℓ 幂整除，而 Acris 完备且 Hausdorff。
2. 取非平凡单位根对应的周期元 μ=tm(ε)−1。源码证明 μ 在 Acris 中非零，并且其在 BdR 中的像也非零。
3. Bcris 是 Acris 对 μ 的局部化。由于 BdR 是域，μ 的像可逆；由局部化的泛性质，j 经 BdR⁺→BdR 后延拓为 ι₀：Bcris→BdR。
4. 利用局部化单射判据和原映射 Acris→BdR 的单射性，证明 ι₀ 仍然单射。
5. 对任意 Core C，ULaws.iota_injective 再用 RingIface.bcris_ext 比较 C.ι 与 ι₀：二者在 Acris 上都等于由 C.j 诱导的映射，因此在整个 Bcris 上相等。于是 C.ι 单射。

ULaws.u_laws 不只是提供 IotaInj；它还同时打包了 u 与 Frobenius 的兼容、u 与 Galois 作用的兼容、ℤ_l 上的标准嵌入、ι 的 Galois 等变性，以及 IsCrisDR。

因此这两项的依赖已能追到具体构造与完备性论证，但其全部传递依赖仍需用 Lean 的 #print axioms 作最终核验。

### 4.3 Fund：Frobenius 固定元的有理性识别

源码：[BcrisFrobeniusFixedFilZeroEqQp.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/IwasawaDecomposition/BcrisFrobeniusFixedFilZeroEqQp.lean)。

目标：

\[
\varphi_B(b)=b,\quad \iota(b)\in\mathrm{Fil}^0
\Longrightarrow
b\in\operatorname{im}(q_B).
\]

源码的证明路线：

1. 通过 Bcris 的 t-局部化表示，将 b 写成 Acris 元素 x 除以 t 的幂；
2. 将 φ_B(b)=b 转换为 Acris 上的 Frobenius 特征方程；
3. 将 ι(b) 的 Fil⁰ 条件结合 t 的过滤次数，转化为 x 的更高过滤条件；
4. 调用 [AcrisFrobeniusEigenFilEqQlMulTPow.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/IwasawaDecomposition/AcrisFrobeniusEigenFilEqQlMulTPow.lean) 中的 fix_pow；
5. fix_pow 证明：若 φ_A(x)=ℓ^r x 且 j(x)∈Fil^r，则存在 z∈ℤ_l、k∈ℕ，使
   [
   ell^k x=z_A,t^r.
   ]
   其 r=0 基础情形由 acris_frobenius_fixed_eq_padicInt 识别。归纳步使用通用 step_abs：先从 Frobenius 分解与 theta 轨道零值推出 μ(ε) 整除相应 Ainf 系数，再构造 x'，满足
   [
   ell^{r+2}x=t x',qquad arphi_A(x')=ell^r x'.
   ]
   随后 fil_div 利用 t 与 xi 相差一个单位因子这一过滤性质，将 j(x) 的过滤阶数降低一级，再应用归纳假设。
6. 利用 ℓ 在 Bcris 中可逆，清除分母并得到某个 c∈ℚ_l，使 q_B(c)=b。

因此 Fund 的核心是“Frobenius 特征方程 + 过滤阶数”共同迫使元素来自 ℚ_l，而不是单独使用 Frobenius 不动性。这里最关键的中间桥梁是 fix_pow 的逐级降阶，而不是一个未展开的黑盒调用。

### 4.4 OneSubPhiOnto：先在 Acris 完备环中解，再清除 t 分母

源码：[BcrisOneSubFrobeniusSurjective.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/BcrisOneSubFrobeniusSurjective.lean)。

目标：

\[
\forall y\in B_{\mathrm{cris}},\quad
\exists x\in B_{\mathrm{cris}},\quad x-\varphi_B(x)=y.
\]

证明的结构比一句“由完备性可解”更具体：

1. **完备环上的基础方程。** 对 ℓ-adically complete 的环，先证明
   \[
   x-\ell\varphi(x)=y
   \]
   可解。证明通过模 ℓ 商上的满射性，再提升到原环。
2. **Ainf 上的高次修正。** 使用 Artin–Schreier–Witt 定理，解出
   \[
   \varphi_A(\beta)-\ell^r\beta=a.
   \]
3. **Acris 中的误差分解。** mul_phi_mem 将 ℓφ_A(x) 表示为 Ainf 项加上 t 乘一个 Acris 项。
4. **局部化清分母。** Bcris 是 Acris 对 t 的局部化；利用 φ(t)=ℓt、t 在 Bcris 中可逆，以及 onto_of_denom 的归纳清分母机制，将 Acris 上的解提升到 Bcris。

其中 one_sub_mul_onto 处理完备性，ainf_onto 处理 Artin–Schreier–Witt 方程，mul_phi_mem 控制 Acris 中的误差项，onto_of_denom 负责局部化后的分母。

### 4.5 PhiSubOneOntoFilZero：用 FundOnto 修正过滤条件

源码：[OneSubPhiOntoOfFilZero.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/PublishedTheorems/GaloisCohomology₂/OneSubPhiOntoOfFilZero.lean)。

分两步：

**第一步：改变符号。** one_sub_phi_onto 给出 x−φx=y。对 −y 使用该结果，即得 φx−x=y。

**第二步：修正 Fil⁰。** 令 h1 为上述满射性，h2 为 FundOnto。对 ι(x) 使用 FundOnto，得到 φ 固定的 b，并满足：

\[
\iota(b)-\iota(x)\in\mathrm{Fil}^0.
\]

因为 φ(b)=b，令 x' = b−x，则：

\[
\varphi(x')-x'=y,\qquad
\iota(x')\in\mathrm{Fil}^0.
\]

因此过滤条件不是在 OneSubPhiOnto 的证明里直接得到，而是由 FundOnto 作一次固定元修正。

### 4.6 FundOnto：构造 Frobenius 固定的过滤近似

源码：[FundamentalMapSurjective.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/FundamentalMapSurjective.lean)。

目标：

\[
\forall w\in B_{\mathrm{dR}},\
\exists b\in B_{\mathrm{cris}},\
\varphi_B(b)=b,\quad
\iota(b)-w\in\mathrm{Fil}^0.
\]

证明中有几个关键构造：

1. exists_exact 是一个完备性修正引理：先构造满足 Frobenius 特征方程且误差高阶可除的近似，再用 ℓ-adic 完备性取极限，将误差提升为精确等式。
2. exists_eigen_int 利用 theta 映射、tilt 元素与 Teichmüller 幂，构造具有指定 theta 值的 Frobenius 特征元。
3. exists_eigen 再利用 ℓ 在 Bcris 与 BdR⁺ 中的可逆性，把具有指定 theta 值的构造提升到 Bcris 与 BdR⁺；其输出仍满足 φ_B(a)=ℓa，并没有把该特征值改成 1。
4. fundOnto 使用 t 的过滤性质和 Filⁿ 由 xi 幂生成的关系，构造满足 ℓφ(s)=s 的辅助元素 s 及相应单位逆元。它与特征值为 ℓ 的元素配对，使乘积的 Frobenius 特征值抵消，再通过归纳不断消除过滤误差。
5. 最后利用 BdR 的域结构和相应分解，将任意目标 w 归约到上述归纳构造。

所以 FundOnto 不是单纯的“固定元空间稠密”：源码给出的是带过滤误差控制的具体构造。

定理包装入口：[FundamentalMapSurjectiveStatement.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/FundamentalMapSurjectiveStatement.lean)。

### 4.7 Regular：有限扩张稳定直线的单位性

源码：

- [BcrisRegularOfTensorInj.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/BcrisRegularOfTensorInj.lean)
- [BcrisRegularOfFullGaloisLineUnits.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/BcrisRegularOfFullGaloisLineUnits.lean)
- [BcrisRegularSurjectionsOfFontaineTheorem.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/BcrisRegularSurjectionsOfFontaineTheorem.lean)

Regular 的定义是：对有限扩张 K，若 b 非零且对所有 g∈G_K，σ_B(g)b 都是某个 ℚ_l 标量乘 b，则 b 是 Bcris 单位。

证明拆为两层：

**A. 先证明全 Galois 稳定直线的生成元是单位。**

- isUnit_of_line 将 theta 为零的情形转化为 theta 非零情形：利用 t 的单位性及 t 幂修正，得到一个 theta image 非零的等价稳定直线生成元。
- isUnit_of_theta 从 BdR 的 theta image 提取连续的 ℤ_l^×-值 character。
- V3.19 已审计的 TateCharacterFiniteOnInertia 给出该 character 在 inertia 上某个幂次后平凡。
- exists_unramified_period_ainf_unit 构造一个 Ainf 单位，使 inertia 方向固定、Frobenius 方向的特征值恰好抵消原 character 的幂。
- 乘积的 theta image 同时被 inertia 与 Frobenius 固定；fixed_of_fixed_inertia_of_fixed_frobenius 将其提升为全 Galois 固定。
- galoisInvariants_Bcris_eq_maxUnramified 将全 Galois 不动元识别到最大非分歧扩张。非零不动元因此是单位；再除去已知的单位因子，得到原 b 的某个幂是单位，进而 b 是单位。

**B. 从全 Galois 稳定直线推广到有限扩张稳定直线。**

regular_of_full 对有限商群 G_Ql/G_K 取共轭轨道乘积：

\[
P=\prod_{q\in G_{\mathbb Q_l}/G_K}\sigma_B(qb).
\]

它证明 P 非零，且 P 张成全 Galois 稳定直线。应用 A 得到 P 是单位。由于 b 是这个有限乘积中的一个因子，b 整除一个单位，所以 b 本身也是单位。

最终 core_regular 调用 bcris_regular_of_full_galois_line_units。

**依赖审计特别发现：** regular_of_tensorInj 的实现形如 fun l _ C _ => core_regular l C。最后一个参数即 TensorInj 被忽略。因此该定理的名字容易造成误读：它并不通过 TensorInj 证明 Regular；Regular 有独立的 stable-line/unit 证明链。

## 5. 最终组装：七字段如何闭合

源码：[FontaineBcrisBasicTheoremsProof.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/FontaineBcrisBasicTheoremsProof.lean)。

- FundOnto：FundOnto.fundOnto；
- Regular：regular_of_tensorInj，但其实际证明独立于 TensorInj。

再由 FontaineBcris.of_rest 补齐 PhiInj、IotaInj 和 PhiSubOneOntoFilZero。

逻辑依赖图：

\[
\begin{array}{c}
\mathrm{TensorInj}\qquad \mathrm{Fund}\qquad
\mathrm{FundOnto}\qquad \mathrm{Regular}\\
\downarrow\qquad\quad\downarrow\qquad\downarrow\qquad\downarrow\\
\multicolumn{4}{c}{\mathrm{FontaineBcris.of\_rest}}\\
\downarrow\\
\mathrm{FontaineBcris}
\end{array}
\]

其中 PhiSubOneOntoFilZero 的子链为：

\[
\mathrm{OneSubPhiOnto}
+\mathrm{FundOnto}
\Longrightarrow
\mathrm{PhiSubOneOntoFilZero}.
\]

而 OneSubPhiOnto 来自完备性、Artin–Schreier–Witt 与 t-局部化清分母。

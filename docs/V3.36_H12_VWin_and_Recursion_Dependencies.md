# V3.36 — H12 primitive inputs: the hidden VWin and recursion dependencies

> Upstream snapshot: CocoSgt/riemann-hypothesis-lean at commit 7cbf7a0c32fca1badf05931879a37c3f8a2b03b4.
>
> Scope: reduce the H12 supply branch one level below HostWW and ObjCP, and state explicitly which high-level analytic inputs remain assumptions of the top-level zero-free theorem.

## 1. HostExW is supplied by VWinAt

For a character psi, SupplyChi.lean proves

\[
VWinAt(\psi,401)\Longrightarrow
HostExW(3/2,GChi(\psi).req).
\]

The proof is short:

1. apply supplyOfAdm;
2. discharge its admissible-rank premise using admissibleClassesTwistedChar;
3. pass the resulting rank and host data into HostExW.

The admissibleClassesTwistedChar theorem is proved from the elementary admissible-rank construction. The nontrivial input is VWinAt.

### What VWinAt says

In ExistsPageN.lean,

\[
VWinAt(\psi,C_t)
\]

requires, for every small epsilon and every admissible PageN exponent function e, a window exponent J ≥ 1 and a threshold X0 such that for all X ≥ X0, all admissible q,d pairs, and all corresponding WinPair data, there is Y with

\[
X^{1/J}\leq Y,\qquad Y^2\leq X,
\]

and for every x in [Y,Y²], the field-count/valuation bound VAt holds.

VAt is itself a uniform statement over every number field E satisfying IsChiField:

\[
VVle\left(E,\lfloor x^{C_t}\rfloor,
\sqrt{\exp(x^\epsilon)}\right).
\]

This is a substantial analytic input. It is not proved by KitS or DesignS.

The paper's top-level theorem makes the same dependency visible: zero_free_all_of_green_v_win takes VWin as an input and uses supplyChi for each character. Thus the H12 data-supply construction is conditional on VWinAt; it does not prove VWinAt.

## 2. The host branch

The host branch is now:

\[
VWinAt(\psi,401)
\Longrightarrow HostExW
\Longrightarrow HostExQW
\Longrightarrow HostWW.
\]

- supplyChi derives HostExW from VWinAt.
- hostExQW_of_hostExW combines HostExW with SmallPrimeOne.
- hostWW combines HostExQW, ObjC, and WClosed.
- WClosed is proved by windowShareRequirementClosedForm_proof.
- SmallPrimeOne is obtained from the proved prime-relation statement.

The local admissible-rank construction is not an extra assumption: admissibleClassesTwistedChar supplies it.

## 3. The object/recursion branch

The object branch is:

\[
\text{RecAtG}+\text{EvP}+\text{SiegelMassRatioCM}
\Longrightarrow \text{RecExP}
\Longrightarrow \text{ObjCP}.
\]

The first implication is recExP_of_recAtG in ExistsLayeredDataOfGoodScaleContexts.lean. It combines:

- RecAtG, a family of good-scale contexts with the required group-retwisting, tuple-use, twisting, and lattice-stability data;
- EvP, an eventual family property for the desired point predicate;
- StandardLattice.SiegelMassRatioCM.

The second implication is existsObjects_of_admissibleTwistDatum. It uses RecExP and LevelPrime to construct the point objects required by ObjCP.

RecAtG itself can be obtained from the two-pass group-retwisting theorem recAtG_of_two_passes, given:

- a volume-to-mass identity for the theta data;
- a base condition for the group-retwisting package;
- the first group condition;
- the export condition;
- the second group condition.

So the recursion branch is explicit, but it still depends on the two-pass group-retwisting and volume/mass inputs.

## 4. The number-theoretic glue is proved

The remaining glue in the construction is not an independent conjectural input:

- MinkDiv is proved by MinkowskiDivisible.lean;
- NormPrimes and LevelPrime are supplied by normPrimes_and_levelPrime_unconditional;
- SmallPrimeOne follows from the proved prime-relation statement;
- WClosed follows from windowShareRequirementClosedForm_proof.

These results allow the host and object branches to be combined without adding another unproved window-existence assumption.

## 5. The complete H12 supply chain

Combining V3.35 and the present reduction:

\[
\begin{aligned}
&VWinAt+\text{admissible-rank construction}
\Longrightarrow HostExW
\Longrightarrow HostWW,\\
&\text{RecAtG}+\text{EvP}+\text{SiegelMassRatioCM}
\Longrightarrow RecExP
\Longrightarrow ObjCP,\\
&HostWW+ObjCP
\Longrightarrow KitCPW,\\
&KitCPW+MinkDiv
\Longrightarrow DesignChoices
\Longrightarrow ExWin.
\end{aligned}
\]

The arithmetic side is separate:

\[
\text{ChainTied/ChainCore}
\Longrightarrow ChainWin.
\]

Then

\[
ExWin+ChainWin
\Longrightarrow TiedWin
\Longrightarrow ZeroFreeLevel.
\]

This is the precise logical division:

- VWinAt supplies the character-specific host/window data;
- RecAtG and EvP supply the recursive arithmetic/geometric objects;
- KitS and DesignS package those into the family required by H12;
- ChainCore supplies the arithmetic estimate on that family;
- TopWin combines the existence and estimate sides.

## 6. The top-level theorem is conditional

The theorem zero_free_all_of_green_v_win assumes:

1. Green;
2. VWin;
3. the definite-side HypsAlt package containing the closed-family LinkN condition.

It then derives ZeroFreeAll. The theorem every_character_of_green_v_win converts this into EveryCharacter.

Consequently, the formal proof chain must be described as a conditional theorem unless Green, VWin, and the definite-side package have themselves been discharged from the intended foundational inputs.

In particular, H12 is constructed from VWinAt; this does not remove VWin from the top-level theorem. A proof summary that says “the Lean code proves H12” without naming VWinAt would hide a material dependency.

## 7. Next upstream targets

The remaining questions are now sharply defined:

1. Can VWinAt(psi,401) be proved from the paper's stated hypotheses, or is it an independent analytic assumption?
2. Can RecAtG be derived from the two-pass group-retwisting inputs and the volume/mass identity without importing an equivalent form of the desired conclusion?
3. What exactly is contained in EvP, and where is its uniformity established?
4. Are Green and the definite-side LinkN package proved elsewhere, or are they top-level assumptions?

These are the real remaining questions for turning the current conditional RH chain into a self-contained proof.

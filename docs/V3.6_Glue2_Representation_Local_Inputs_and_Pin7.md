## 1. `PsiEx)：由 `KillsMu` 下降为模 (l) 的 Dirichlet character

定义：[RhoFrob.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/RhoFrob.lean)

命题内容：

[
chi:G_{mathbb Q,Omega}	ooverline{mathbb Q}_l^	imes,quad
operatorname{KillsMu}(l,chi)
]

推出存在模 (l) 的复 Dirichlet character (psi)，使

[
chi(s)=iota^{-1}!left(psi(operatorname{cyc}_1(s))ight).
]

证明：[PsiEx.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/PsiEx.lean)

关键步骤：

1. 证明若 (operatorname{cyc}_1(s)=operatorname{cyc}_1(t))，则 (t^{-1}s) 固定所有 (l) 次单位根；
2. 由 `KillsMu` 得 (chi(t^{-1}s)=1)，因此 (chi(s)=chi(t))；
3. 证明 (operatorname{cyc}_1) 是群同态且满射到 ((mathbb Z/lmathbb Z)^	imes)；
4. 选取每个模 (l) 单位的 Galois 原像，定义因子 character；
5. 用满射和乘法相容性验证它确实是 Dirichlet character。

这是一个标准的商群因子化论证：(chi) 对 cyclotomic 核平凡，所以通过模 (l) cyclotomic quotient 因子化。

## 2. `FrobU)：Frobenius 存在且普通对角元范数为 1

定义：[RhoFrob.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/RhoFrob.lean)

`FrobU) 要求：

- 在 (A) 的分解群中存在一个 (l)-Frobenius 元素；
- 对所有分解群元素 (s)，普通对角元 (W_{11}(s)) 的 (l)-进范数等于 1；
- cyclotomic character (arepsilon_l(s)) 的范数等于 1。

证明：[FrobUNormV.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/FrobUNormV.lean)

第一部分从 `Nf.atL) 取得 (l) 上方的素点，再调用 `exists_isFrob) 找到 Frobenius 元素。

第二部分使用：

- `Nf.upper)：矩阵上三角；
- `Nf.int)：矩阵元素落在系数环；
- `CupCob.norm_le_one_of_mem)：整元素的范数不超过 1；
- (W(s)W(s^{-1})=I)。

上三角条件使矩阵乘积的 ((1,1)) 项就是两个对角元的乘积，于是
[
|W_{11}(s)|_l,|W_{11}(s^{-1})|_l=1.
]
两因子都不超过 1，因此两者都必须等于 1。

第三部分直接使用 cyclotomic character 的值属于 (l)-进单位。

## 3. `DetIne)：从 newform Frobenius 特征多项式推出惯性行列式关系

定义：[RhoFrob.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/RhoFrob.lean)

结论：
[
orall sin I_A,qquad det W(s)=chi(s)^2.
]

证明：[DetIne.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/DetIne.lean)

这一步使用了一个比局部矩阵计算更强的工具：**Chebotarev degree-one 密度**。

证明思路：

1. 由 newform (g) 的模数 (M)，选取 (M) 阶 primitive root (zeta)；
2. 构造函数
   [
   F(zeta^k)=iota^{-1}(g.chi(k));
   ]
3. 构造连续函数
   [
   f(t)=det W(t),chi(t)^{-2};
   ]
4. 在避开有限坏素数集合的 Frobenius 元素上，用 `g.Att) 给出的 Hecke 特征多项式比较 (ho) 的迹与行列式；
5. 用 `det_of_charpoly` 将特征多项式常数项转成行列式；
6. 利用 `cycBar) 在 Frobenius 元素处等于相应素数范数，推出 (f(t)=F(tzeta))；
7. 由 Chebotarev degree-one 定理和连续性，将稠密 Frobenius 集上的等式延拓到整个 Galois 群；
8. 对惯性元素 (s)，因 (l
mid M)，惯性作用固定 (zeta)，故 (F(szeta)=F(zeta)=1)，最终得到 (det W(s)=chi(s)^2)。

这不是仅靠 `Nf) 的局部上三角条件就能得到的结论；newform 对应关系与 Chebotarev 是关键输入。

## 4. `HatW)：Eisenstein Fourier 系数的非零、范数与周期性

## 5. `SmNz)：四项平滑组合的非零性

定义：[RhoFrob.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/RhoFrob.lean)

[

以及四个模数位置：
[

[

先证明 (N,Nc,Nd,Ncd) 均不被 (l) 整除，因此对应 character 值范数为 1。随后把四项展开并因式分解：

[

={}&N^epsi(N)^{-1}c^2c^{-e}\
&cdot(c^e-apsi(c)^{-1})\

- (l

- (|a|=1) 且 (|psi(c)|=1)，而假设排除 (c^e) 落在单位圆上；

这是一个纯代数的四项因式分解，不是数值估计。

## 6. `GmEx)：显式构造模 (l) 矩阵

定义：[ThickFrames.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/ThickFrames.lean)

`GmEx) 要求对每个 (r_0in(mathbb Z/lmathbb Z)^	imes)，存在
[
gm(r_0)in SL_2(mathbb Z)
]
满足：

- (gm(r_0)inGamma_1(N))；
- 左下角元素被 (N) 整除；
- 模 (l) 后左下角与左上角满足指定关系；
- 行向量 ((0,1)) 在模 (l) 作用下成为目标向量的单位倍。

证明：[GmEx.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/GmEx.lean)

显式选择
[
gm(r_0)=
egin{pmatrix}
1&0\
Nm(r_0)&1
end{pmatrix},
]
其中 (m(r_0)) 是 (-r_0N^{-1}) 在 (mathbb Z/lmathbb Z) 中的整数代表。矩阵行列式显然为 1，模 (l) 关系由
[
Nm(r_0)equiv-r_0pmod l
]
直接验证。

这是一个完全显式的构造，不依赖抽象存在性。

## 7. `ExplSmul)：乘以 (l^m) 后保持同余结构

定义：[RhoFrob.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/RhoFrob.lean)

`ExplSmul) 的目标是：若 `Expl) 对常数 (kappa) 成立，则对
[
kappa' = l^mkappa
]
仍然成立。

证明：[ExplSmul.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/ExplSmul.lean)

关键事实：
[
|l^m|_lle1.
]
若 (aequiv bpmod{l^n})，则
[
l^m aequiv l^m bpmod{l^n},
]
因为超度量范数满足
[
|l^m(a-b)|_l=|l^m|_l,|a-b|_lle|a-b|_l.
]

同样，系数整性在乘以 (l^m) 后保持。该定理用于后续统一调整常数而不破坏既有同余关系。

## 8. `PinOf)：把前面所有信息组装成 `Pin7)

定义：

- `PinOf)：[RhoFrob.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/KatoQuadraticCharacters/FrobeniusHodgeTateLaws/RhoFrob.lean)
- `Pin7)：[HTPresNuOfPolys.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AbelianVarietyTheory/Definitions/Foundations/HTPresNuOfPolys.lean)

`Pin7) 是一个完整的局部 (l)-进插值包，包含：

- 一个 Frobenius 元素及其单位特征值 (a)；
- 单位 (a')；
- 非零常数 (kappa)；
- 范数为 1 且逐层 Cauchy 的序列 (v_m)；
- valuation embedding (j)；
- 幂级数 (L) 与模 (l) character (phi)；
- `HTLawCsOfCoef)；
- primitive-character 在根单位处的同余公式；
- 从 (L) 的质量和得到的最终非消失条件。

`pinOf) 的证明结构：

1. 调用 `Meas3)，取得整系数幂级数 (L)、(kappa)、(phi) 和 mass 非消失界；
2. 调用 `CoefUb)，把 (L) 的系数并入当前系数环；
3. 从 `Expl) 取得 (kappa_0,v_m,m_0,c_0) 与 Hodge–Tate law；
4. 用 `cg_cases) 选择足够大的层级阈值；
5. 调用 `Mono)，把 `HTLawCsOfCoef) 提升到新的系数环；
6. 利用 `Meas3) 的两种奇偶性 Gauss-sum 公式，证明 `Pin7) 中的 primitive-character 同余；
7. 将 `Meas3) 的最终 mass 非消失条件直接带入 `Pin7)。

这说明 `PinOf) 是 Kato 构造的一个重要组装器：它把测度、幂级数、valuation、Frobenius 和 Hodge–Tate 数据统一到一个可以被全局 glue 使用的对象中。

## 10. 本轮结论与下一步

### 已核实

- `PsiEx) 是 cyclotomic quotient 因子化；
- `FrobU) 是 Frobenius 存在与普通对角元范数控制；
- `DetIne) 依赖 Chebotarev degree-one，将 newform 的 Frobenius 数据延拓到惯性群；
- `HatW) 由有限 Fourier 变换可逆性和超度量范数界得到；
- `SmNz) 是可显式因式分解的非零性；
- `GmEx) 有具体矩阵公式；
- `ExplSmul) 是 (l^m)-缩放下的同余稳定性；
- `PinOf) 将这些数据与 V3.5 的 `Meas3)、`CoefUb)、`Mono) 组合成 `Pin7)。

# V3.46 — Dimension-free lattice-tower trace transfer

## Scope

Alternative natural-language proof of GlobalTheory.CoverTrace.trace_pow_eq, called through GlobalTheory.T.trace_pow_eq_along_latticeTowerCover in ClosedOfCover.lean (V3.45 §5.3). The source already uses ultrametric matrix estimates and zero-th moment normalization. The improvement here is a single maximum-norm argument, a sharper telescoping bound, and elimination of the coefficient normalization by a cross-product identity. It is a simplification of exposition under the exact upstream hypotheses, not a new mathematical theorem of claimed priority, not a proof of the entire period closure, and not a newly kernel-checked Lean script.

Pinned upstream commit: 7cbf7a0c32fca1badf05931879a37c3f8a2b03b4.

## 1. Abstract scalar transfer lemma

Let F be a non-Archimedean normed field. Equip all finite matrices, rectangular matrices, row vectors and column vectors with the maximum entry norm (maximum of the empty set is zero). For compatible dimensions,
    ||AB|| ≤ ||A|| ||B||,
    ||A+B|| ≤ max(||A||,||B||).
This is immediate from the ultrametric inequality for finite sums, and has no factor depending on the dimension. Identity matrices have norm at most one, including the zero-dimensional case.

Fix a target dimension d, a d×d matrix U, row t, column v, and moments X_n=t U^n v. Assume X_0=a=S_0, where a is a nonzero scalar and S_n is a prescribed sequence in F.

For every precision index N, suppose there is a layer (its dimension may depend on N), with square matrix V, rectangular P, column w, row T, and scalar C such that
    ||U||,||V|| ≤ B, B≥1,
    ||w|| ≤ 1,
    ||v−Pw|| ≤ ε_N,
    ||UP−PV|| ≤ B ε_N,
    ||tP−T|| ≤ ε_N,
    T V^n w = C S_n for every n≥0,
where ε_N→0 and B is independent of N. There is no need to bound C, T, P or the layer dimension. In fact the moment equality is needed only at 0 and the fixed n being proved.

Conclusion:
    X_n=S_n for every n≥0.

## 2. Proof in two identities

For n≥1, telescoping gives
    U^n P−P V^n = Σ_(j=0)^(n−1) U^(n−1−j)(UP−PV)V^j.
Consequently
    ||U^n P−P V^n|| ≤ B^(n−1)||UP−PV|| ≤ B^n ε_N.
For n=0 the left side is zero, so the last bound also holds. The source proves the weaker B^n ||UP−PV|| by induction. This telescoping bound is stronger by one power of B for n≥1.

Put H=max(1,||t||). Adding and subtracting the transported moments yields the exact identity
    X_n−C S_n
      = t U^n(v−Pw)
        + t(U^n P−P V^n)w
        + (tP−T)V^n w.
Each term has norm at most H B^n ε_N. Therefore, by the strong triangle inequality,
    |X_n−C S_n| ≤ H B^n ε_N.                         (1)

At n=0 this gives |a−Ca|≤H ε_N. There is no need to show the sequence of scalars C is itself Cauchy or first extract a limit of the layer data. Eliminate C algebraically:
    a(X_n−S_n)=a(X_n−C S_n)−S_n(a−Ca).
Divide the ultrametric bound by |a|>0 to obtain
    |X_n−S_n| ≤ H max(B^n, |S_n|/|a|) ε_N.          (2)
All factors except ε_N are fixed for each n. Let N→∞. This proves the lemma.

This is exact also when the residue characteristic divides a: a can have small norm but is nonzero in characteristic zero, and its inverse norm is a fixed finite constant. No reduction modulo the residue field is used.

A slightly more general formulation allows unit, commutator and read errors α_N, δ_N, β_N tending separately to zero. For n≥1,
    |X_n−C S_n| ≤ max(||t|| B^n α_N, ||t|| B^(n−1) δ_N, B^n β_N)
if ||w||≤1; for n=0 omit the middle term. Thus the same argument requires only simultaneous vanishing errors, not a common exponential rate.

## 3. Exact instantiation in the Lean cover

Use F=C_ℓ, the completed algebraic closure, and the given Cover L0 r Cl with target dimension Cv.d and layer dimension Cv.tw.d' m. Let f:Qbar_ℓ→C_ℓ be the coefficient embedding composed with the fixed Galois automorphism σ, and Z:Z_ℓ→C_ℓ the canonical embedding. The source proves f is isometric and f(zOm x)=Z(x).

Define:
    v_i=Z(Cv.e_i),
    t_i=f(Tr(Cv.b_i)),
    X_n=t U^n v.
Linearity of matrix trace identifies X_n exactly with the target expression of trace_pow_eq.

For a precision index N choose m≥N supplied by hcomm. Use:
    V=U'_m,
    P=Z(Cv.tw.Pi_m) entrywise,
    w_s=Z((Cv.lay m).e_s),
    t'_(k,s)=f(Tr((Cv.lay m).b_(s,k))),
    T_s=Σ_k f((Cv.lay m).c_k) t'_(k,s),
    C=Σ_k f((Cv.lay m).c_k),
    B=max(1,Bd), ε_N=ℓ^(−N).

The correspondence of hypotheses is exact:

| Abstract condition | Upstream field or argument |
|---|---|
| ||U||,||V||≤B | hU and hU' |
| ||w||≤1 | the entries of the layer read vector lie in Z_ℓ |
| ||v−Pw||≤ε_N | Cv.unit m: divisibility of Pi_m e_m−e by ℓ^m, and m≥N |
| ||UP−PV||≤B ε_N | hcomm N, with Bd≤B |
| ||tP−T||≤ε_N | Cv.trace m, transported by the isometry f and f∘zOm=Z |
| t'_k V^n w=S_n for all k | htr, rewritten by linearity of trace |
| T V^n w=C S_n | sum of the preceding exact equalities with coefficients f(c_k) |
| X_0=a | Cv.reads.one (the target read of its identity is the a×a identity) |
| S_0=a≠0 | hS0, a≥1 and characteristic zero |

All sums are finite. Importantly the coefficients may be unbounded as N varies; the hypothesis controls the combined row T, not individual coefficients. Equation (2) eliminates their sum without requiring coefficient bounds.

Hence
    |X_n−S_n| ≤ max(1,||t||) max(B^n, |S_n|/|a|) ℓ^(−N)
for every N. Since ℓ≥2, the right side tends to zero. The desired trace equality follows for every n.

The proof does not require layer dimensions to be bounded or matrices of different sizes to converge. It uses only the unit, trace and approximate-intertwining data of the cover, plus the exact per-layer common moment. The additional structural fields of Cover are relevant to obtaining these data upstream, but not needed in this scalar estimate once they are supplied.

## 4. Comparison with the upstream core

The upstream core estimate is
    |X_n−C S_n|≤B^n ε τ+B^n δ τ+B^n ε,
where τ=Σ_i |t_i| is one bound for each entry, δ=B ε_N in the application. It then estimates |C−1| using n=0 and takes an ordinary triangle inequality again.

Our direct maximum-norm bound is
    |X_n−C S_n|≤B^n ε_N max(1,max_i|t_i|).
Both establish the same limiting conclusion. The new bound removes the artificial extra factor B in the commutator term and additive accumulation of three errors. It is also no larger than the upstream bound, because max_i|t_i|≤τ and B≥1.

The elimination step is an exact identity and does not change any quantifier: the same m and C work for moments n and 0. It would be invalid to take unrelated layers with unrelated coefficients for those two moments.

## 5. Boundary and next dependency

This establishes the trace-power-transfer interface from the already constructed cover and period operators. In ClosedOfCover.lean the operators are supplied by adapted Hodge bases and bounded compatible Breuil–Kisin frames, while the common seed moments are obtained from the fixed jump multiset. V3.45 §5.3 then recovers the weights using Newton identities and injectivity of h↦z^h.

What is not established here: existence of a uniformly bounded compatible period-frame tower, or its limit frame. That is the next deep input to reconstruct. This proof should not be misread as an argument that arbitrary local p-adic representations have stable Hodge weights under mere trace convergence.

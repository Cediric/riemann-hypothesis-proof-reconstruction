### 1.1 两个关键输入不是一个名字，而是完整的命题

`SmoothedZetaClassHodgeTateLawStatement.lean` 定义两个大命题：

- `KatoEulerSystemIwasawaClassStatement)：对给定素数 (l)、数域代数闭包、奇数权 newform (g)、局部二阶表示 (W)、valuation ring (A)、cyclotomic tower (X) 和 admissible Hecke 数据，构造一个有限层修正后的系数环 `cf')、有限集 (S')、Iwasawa 系列 (Y_r) 与函数 (y)，满足：

- `SmoothedZetaClassHodgeTateLawStatement)：在上述 cocycle 数据之外，进一步要求 admissible Hodge–Tate zeta-class 参数，并构造非零常数 (kappa)、单位范数的 (v_m) 和一个 `HTLawCsOfCoef) 关系，把 smoothed zeta class 的系数与 Kummer/Eisenstein 侧的显式表达式联系起来。

这两者都不是一句“由 Kato 定理可得”；它们是非常强的结构性存在命题。

## 2. LemmaK：对全局 H² 长度的 discriminant 界

`GeneratorCountTuples/LemmaK.lean` 定义：
[
kBound(C,e,n,D)
=
exp!left((2en)^Clog(2D)ight).
]

`LemmaK(C_K)) 要求对每个素数 (l)、totally complex 数域 (L)（满足 (mu_lsubset L)）、Galois 数据 (D) 和 (ege1)：

1. (H^2(zlTw(D,e+1))) 有限；
2. [
   log#H^2(zlTw(D,e+1))
   le
   kBound(C_K,e,[L:mathbb Q],|operatorname{disc}L|).
   ]

它是一个非常具体的 cohomology torsion-growth 界：增长对 (e) 和域次数是指数型，但指数的底数只以多项式进入；判别式以对数进入。

`LemmaKOfPublished.lean` 的主定理：
[
	ext{PoitouTate}+
	ext{LocalFiniteness}+
	ext{LocalTateDuality}+
	ext{KBridge}+
	ext{torsMain}
Longrightarrow
exists C_K, mathrm{LemmaK}(C_K).
]

其中 `torsMain) 来自 Hermite normal forms；`KBridge) 是 generator-count/torsion 的代数桥梁。顶层 `lemmaK_litN_alt) 再从 `LiteratureRankNHypothesis) 和 `bOdd) 构造所需的 `KBridge) 输入。

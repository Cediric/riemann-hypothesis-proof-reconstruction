## 1. 先区分三种长度：Sha、VLen、Vlen

### 1.1 全局 Sha 长度

`Formalism/GaloisCohomology/Statement.lean` 定义：
[

[

=operatorname{length}_{mathbb Z_l}operatorname{Sha}(D,e).
]

这才是 `VVle) 最终求和的量。

### 1.2 全局二阶上同调长度

同一文件定义
[

]

`VLen) 与 `shaLen) 不是同一个对象；二者的联系需要 Poitou–Tate、局部 Tate 对偶及局部/全局有限性等结果。

## 2. 六种主要 Case 的分工

`Counts.lean` 中：

- `CountI)：对有限素数集 (L_s) 中所有满足 `CaseI` 的素数，把 (log l) 乘以同一 host 中所有特征的 (Vn) 求和，给出 ((N t)^C) 级的整体上界；
- `CountII)、`CountIII)：对单个素数和特征，在 CaseII/III 下给出 (VLe) 的多项式界；
- `CountIV)：处理 (lin B_chi) 的 ramified 情形，覆盖特定奇数阶特征；
- `CountV)：处理 CaseV 且 (R_1(l,psi)le 2^{c_2(psi)})；
- `CountVs)：处理 CaseV 的互补情形 (2^{c_2(psi)}<R_1(l,psi))；
- `CountZ)：处理 CaseZ，使用 `PropZ) 令对应的局部 (V) 量直接为零。

`CountIV) 与 `CountVs) 不能省略：虽然 V3.1 的简写列表主要写 CountI/II/III/V/Z，但 `pointHV_of_counts) 的 `sumIn) 还明确调用了 `countVs) 和 `countIV)。

### 3.1 OneChar 的核心输出

2. `exists_uLoc)、`exists_ring)、`exists_model) 构造局部环与三维表示族；

## 5. CountIV、CountV、CountVs、CountZ：补齐剩余局部情形

[

## 6. 从局部 Count 汇总成全局 Sha 窗口界

### 6.1 SumOut：非 ramified 素数

`SumOut.lean` 把素数集按 `CaseI) 与其补集拆分：

- CaseI 部分用 CountI 的全局和界；
- 非 CaseI 部分用 CountII/III/Z 及 host 的例外素数计数界；
- 再由 `redPrime) 将 `plusLen) 转成 (Vlen) 与 loss 项。

### 6.2 SumIn：ramified 素数

`FinalLe.lean` 的 `sumIn) 组合：

- CountIV；
- CountV；
- CountVs；
- 由 host 条件得到的 character 数量上界；

### 6.3 PointHV 与 ThmHV

`JointWinOfCounts.lean` 中：
[
mathrm{PointHV}
=
mathrm{point}(mathrm{sumIn},mathrm{sumOut}).
]

`pointHV_of_counts) 的输入明确包括 Poitou–Tate、LocalFinitenessK、LocalTateDualityK、LemmaK、CountI/II/III/V/Z；并在内部调用 `countVs) 与 `countIV)。

随后 `thmHV_of_counts) 将 PointHV 提升为 `ThmHV)，`jointWin_of_counts) 再与 `ThmBab) 组合成 `JointWin)，最终由 `vwin_of_joint) 与 `ThmBcFree) 得到 `VWin)。

这就是 Count 系统的完整逻辑：局部 (Vlen) 界 → 分层 `plusLen) 界 → 全局 `PointHV/ThmHV) → `JointWin) → `VWin) 的 Sha 长窗口界。

## 7. 本轮审计结论

1. `VVle) 的目标量是 `shaLen)，而 CountI/II/III/IV/V/Vs/Z 主要先控制 `Vlen/Vn)；二者通过局部/全局对偶、Euler 特征、H0 损失与 `redPrime/redAll) 连接。
2. CountI 是 Kato/Bloch–Kato + automorphy + 三维表示 Frobenius trace 估值的全局轨道和。
3. CountII/III 是 SP4 四维辛像与 adjoint lifting 给出的局部共振情形界。
4. CountIV/V/Vs 覆盖 ramified 和 (R_1) 大小的剩余情形；CountZ 处理平凡特征的零项。
5. 这些界被 `SumIn/SumOut) 完整拼成 `PointHV)，再推到 `VWin)。

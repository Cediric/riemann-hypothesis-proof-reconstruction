## 1. The exact descWeak consumed by VWin

WindowBoundOfLiteratureLevel.lean calls:

\[
\texttt{published\_hypotheses\_from\_patching\_alt}
\ h_N\ \texttt{UpperTheory.V.Z.Tf.SR.descWeak}.
\]

The theorem passed here is UpperTheory.V.Z.Tf.SR.descWeak from SplitRigidity/HasOfSplit.lean. It is not the similarly named theorem UpperTheory.V.Z.Tf.GaloisFromTraceFormula.descWeak, which has an additional GalWeak 4 argument.

The proposition UpperTheory.V.Z.Desc.DescWeak concerns CM number fields E, a finite set S of places containing the places above a chosen rational prime and all places lying above split places, and cuspidal representations π of rank n with 2 ≤ n ≤ 4. Under regular-algebraic and conjugate-self-dual hypotheses, and given Satake data outside S, it constructs a unitary automorphic representation σ such that:

- σ is unramified at every nonsplit place;
- at almost every split place, the local component of σ matches a local representation τ whose Satake parameters match those of π.

This is the automorphic descent statement used by the VWin proof.

Source: [DescWeak.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/CuspidalDescent/DescWeak.lean), [HasOfSplit.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/TraceFormula/SplitRigidity/HasOfSplit.lean).

## 2. The RunTh dichotomy

EvaluationAtUnitaryOne.lean defines RunTh as a dichotomy. For each admissible E, n and π, one gets either:

**Branch A — an automorphic unitary representation.**

There exists a unitary representation σ which is unramified outside the split places and whose local components match π's Satake data at almost all split places.

**Branch B — a finite obstruction datum.**

There exists D with:

- D does not contain π;
- D is regular;
- outside split places, D has the prescribed Satake data;
- at almost all split places, D has Satake data compatible with π.

The second branch is designed to be ruled out by split rigidity.

Source: [EvaluationAtUnitaryOne.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/TraceFormula/GaloisFromTraceFormula/EvaluationAtUnitaryOne.lean).

## 3. How RunTh is assembled

DescWeakOfPi.lean constructs RunTh from the following inputs:

- G2.uSide;
- G2.g2s;
- muEx;
- G2.matchUnit;
- G2.matchSplit;
- Th.stUnit;
- endoBlockG;
- stableBlockG.

The last two are built using the cusp-read input and the five Pi-side statements:

- PiTerm;
- PiFin;
- PiAdm;
- TwTrSum;
- GrowthPiJ.

The theorem runTh in DescWeak.lean supplies those five inputs using Pi.piTerm_holds, Pi.piFin_holds, Pi.piAdm_pf, Pi.twTrSum_pf, and Pi.growthPiJ_holds.

This is the global trace-comparison portion of the descent proof. It produces a dichotomy between a genuine automorphic representation and a finite obstruction package; it does not simply assume the desired automorphic representation.

## 4. Eliminate the obstruction branch by split rigidity

HasOfSplit.lean proves:

1. Assume the obstruction branch gives D with D.Reg, D does not contain π, and the required Satake matching at almost all split places.
2. Apply has_of_split.
3. This invokes splitRigid together with unitOf and partNorm to show D actually contains π.
4. This contradicts the branch's assertion that D does not contain π.

Therefore only Branch A remains, yielding DescWeakAll. The theorem descWeak then specializes this to the rank range 2 ≤ n ≤ 4 and the finite set of places required by the definition of DescWeak.

The critical point is that the finite obstruction is not discarded by an informal argument: the code proves it contradicts the split-rigidity theorem.

Source: [HasOfSplit.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/TraceFormula/SplitRigidity/HasOfSplit.lean), [SplitRigid.lean](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/7cbf7a0c32fca1badf05931879a37c3f8a2b03b4/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/TraceFormula/SplitRigidity/SplitRigid.lean).

## 5. How it enters VWin

The VWin chain is now more explicit:

\[
\begin{aligned}
&\texttt{LiteratureRankNHypothesis}\ h_N
  + \texttt{SR.descWeak}\\
&\qquad\Longrightarrow \texttt{HypothesesH'}\\
&\qquad\Longrightarrow \texttt{VWin}.
\end{aligned}
\]

published_hypotheses_from_patching_alt fills the HypothesesH' structure with:

- litN := hN;
- cohC from the Clozel cohomology construction;
- conjC and Borel injectivity;
- Galois representation existence over totally real fields;
- strong multiplicity one and Gelfand–Kazhdan inputs;
- admissible real/base-change data;
- descU := SR.descWeak;
- the remaining cyclic/base-change, twisting, and semisimplicity fields.

Then vwin_of_hypotheses_H_E_alt uses this package to establish the uniform arithmetic window bound.
